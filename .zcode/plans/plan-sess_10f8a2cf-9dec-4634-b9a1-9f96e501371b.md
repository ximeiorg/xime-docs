将文档首页 Hero 区右侧的效果图替换为 `容器 6.webp`。

背景：新图（672×1361，带透明背景）本身就是一张完整的手机样机图（含边框、灵动岛、曦码输入法设置页 + 键盘截图），而首页目前是用 CSS 画的手机边框（`.x-phone-frame/notch/screen`）内嵌 `keyboard.jpg` 拼出来的。因此不再往旧边框里塞图，而是整块替换为这一张图。

改动内容：

1. **复制图片**
   - `/home/kkch/下载/容器 6.webp` → `docs/public/hero-phone.webp`

2. **修改 `docs/.vitepress/theme/components/CustomHome.vue`**
   - 将 Hero 右侧的 `<div class="x-phone-frame">…</div>` 整块（frame/notch/screen/keyboard/gradient）替换为一个 `<img src="/hero-phone.webp" alt="曦码输入法界面预览" class="x-hero-shot" />`

3. **修改 `docs/.vitepress/theme/custom.css`**
   - 删除 `.x-phone-frame / .x-phone-notch / .x-phone-screen / .x-phone-keyboard / .x-phone-gradient` 及其 `::after` 样式
   - 新增 `.x-hero-shot`：宽度约 280px、`height: auto`、`filter: drop-shadow(...)` 保留悬浮投影效果（图片自带透明边框，drop-shadow 比 box-shadow 更贴合轮廓）
   - 更新两处响应式断点（960px / 768px）中的手机尺寸规则，改为对应缩小 `.x-hero-shot` 宽度（如 230px / 200px）

4. **验证**
   - 运行 `npm run docs:dev` 启动本地预览，确认浅色/深色模式下图片显示与窄屏响应式正常

`keyboard.jpg` 保留在 public 目录不动，仅首页不再引用。
