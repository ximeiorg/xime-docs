# 使用与设置

本文按「键盘 → 候选栏 → 菜单 → 面板 → 语音 → 设置页」的顺序介绍鸿蒙版的日常使用。

## 键盘

弹出键盘后默认是当前方案的全键盘布局，右上/右下角可切到其他键盘形态：

| 键盘 | 说明 |
|------|------|
| 全键盘 | 五笔 / 拼音等方案的主键盘，包含候选栏与工具栏 |
| 九键（T9） | 九宫格布局，拇指友好，单手操作更轻松 |
| 数字 | 只含数字与常用符号，适合输入号码与金额 |
| 符号 | 常用符号与全量符号两张表 |
| 表情 | Emoji 多标签网格，点击直接上屏 |
| 编辑面板 | 复制 / 粘贴 / 全选 / 剪切、段首 / 段尾、方向垫与选择模式 |

- **高度调节**：拖键盘顶部的调节条，或在菜单里点「键盘调节」。
- **单手模式**：菜单「单手模式」，键盘整体向左或向右收拢。
- **悬浮模式**：菜单「悬浮模式」，键盘变成可拖动的悬浮窗，再次点击退出。
- **横屏**：自动切成左右分体键盘，双手持握时两侧各一半。
- **平板 / 大屏**：设备最小边 ≥ 600vp 时切到大屏档位，仍是一套布局，只调整键位尺寸与边距。

## 候选栏

- 候选按顺序编号，点候选或按数字键选词；空格选第一个候选，回车上屏编码并换行
- 候选栏右端的「更多」按钮进入**候选展开页**：左栏是快捷符号与候选/单字切换，中间是分行分组的候选列表，右栏是退格、上下翻页与回车
- **编码显示**：编码不走悬浮气泡，而是通过系统 `setPreviewText` **预上屏**到应用编辑框内（与华为系统键盘同款形态）。可在「布局与显示」里关掉编码显示
- **候选栏最近剪贴板**：复制后 30 秒内弹出键盘，候选栏右侧会出现刚复制的文本，点一下即可上屏；超过 30 秒或已点选过的条目会自动收回

## 菜单

键盘工具栏最右侧的菜单按钮，按页展开功能入口：

| 第一页 | 作用 |
|--------|------|
| 剪贴板 | 打开剪贴板面板，查看历史并点击上屏 |
| 快捷发送 | 常用短语列表，点击上屏 |
| 输入方案 | 方案列表，切换当前方案 |
| 方案开关 | 打开/关闭已启用方案（如简入繁出、标点、模糊音等开关项） |
| 表情 | 打开表情网格 |
| 定制工具栏 | 选择候选栏上显示哪些按钮 |
| 单手模式 | 键盘左右收拢 |
| 键盘调节 | 调整键盘高度与边距 |

| 第二页 | 作用 |
|--------|------|
| 深色模式 | 在浅色 / 深色之间切换（也可跟随系统） |
| 悬浮模式 | 切换悬浮键盘 |
| 部署方案 | 重新加载 Rime 配置并重建方案产物 |
| 选择输入法 | 打开键盘内的输入法选择页（长按地球键同样进入） |

修改方案、词典或 `xime.custom.yaml` 之后，务必点「部署方案」，否则改动不生效。

## 剪贴板与编辑

- **剪贴板面板**：列出本机剪贴板历史，点击条目直接上屏。历史只保存在本机，不上传。
- **最近剪贴板**：只在候选栏出现 30 秒，适合「复制一段话，立刻粘到聊天框」这种场景。
- **编辑面板**：复制、粘贴、全选、剪切，快速跳到段首 / 段尾，删除与回车；中间的方向垫可以逐字移动光标，点中心圆进入**选择模式**，此时方向键扩展选区。
- **粘贴**：编辑面板的粘贴走输入法直读系统剪贴板后插文，不依赖编辑框响应 `PASTE` 命令，因此在多数应用里都可用。

## 语音输入

鸿蒙版使用**华为 Core Speech Kit** 做离线语音识别：

1. 在「设置 → 语音转文本」中打开语音输入开关
2. 键盘工具栏或菜单里的语音按钮开始听写
3. 说话时面板显示识别进度，停顿后文本自动上屏
4. 再点一次或关闭面板结束

语音识别在本机完成，录音不上传。基础访问模式下扩展进程拿不到麦克风权限，语音入口会不可用。

## 设置页

打开桌面上的「曦码输入法」应用，即进入设置页。

| 页面 | 作用 |
|------|------|
| 启用输入法 | 引导到系统设置中启用并选择曦码输入法 |
| 主题与定制 | 主题选择与配色，即选即生效 |
| 按键效果 | 按键音效、振动反馈、按键气泡 |
| 布局与显示 | 横屏分体键盘开关、剪贴板历史记录开关、候选词编码显示与数量、数字框自动数字键盘 |
| 输入方案 | 方案列表、启用/停用、从文件导入、无线导入、已导入文件管理、部署 |
| 词库管理 | 用户词典的查看、新增、删除、刷新快照；快捷短语（开发中） |
| 智能联想 | 基于本地模型的联想词预测开关与强度 |
| 智能纠错 | 按错相邻键时在候选栏给出纠正候选 |
| 语音转文本 | 语音输入开关 |
| 设备互联 | 局域网设备配对与剪贴板同步，步骤见[手机端（鸿蒙）](/device-link/harmony) |
| 关于曦码 | 版本、开发者、联系方式 |

> 设置页与输入法扩展是**两个进程两个沙箱**，靠签名 Profile 里的 `data-group-id` 共享数据。改完设置建议重新弹出一次键盘，让扩展读到最新的共享配置。

## 数据与配置

所有 Rime 数据在输入法扩展的沙箱目录下：

```
<扩展沙箱>/files/
├── rime/                  # 方案、词典、用户配置、build/ 部署产物
│   └── xime.custom.yaml   # 主题与行为自定义（覆盖 xime.yaml）
└── models/                # 本地模型（联想等）
```

- 主题、按键效果、键盘高度等 UI 设置存在 `preferences` 里，不落在 `rime/` 下。
- 备份建议用「词库管理」导出用户词典，方案用「输入方案 → 从文件导入」重新导入；整目录备份需要设备已 root 或使用系统备份能力。
- 部署失败时用 `hdc shell hilog` 看 `XimeRimeConfig` 的日志，`rime/build/*.log` 里会有具体的词库编译错误。

## 与 Android 版的差异

鸿蒙版是 Android 版的移植，功能对齐但有明确的裁剪：

- 没有插件体系与扩展商店，因此也没有 AI 回复 / AI 写作 / 表情包脚本这类插件功能
- 没有手写输入
- 编码显示改为预上屏，不再是候选栏内的悬浮编码气泡
- 长按地球键走键盘内的选择页，而不是系统弹窗

对照表见[功能文档](/features/)，平台差异以本页与[常见问题](/harmony/faq)为准。
