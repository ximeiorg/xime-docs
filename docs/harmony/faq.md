# 常见问题

## 在哪里下载安装包？

**暂时没有公开发布的安装包**。鸿蒙版仍在内测，目前只支持从源码自行构建，产物是一个签过名的 `.hap`。

如果需要试用，请按[总览与安装](/harmony/install)的步骤准备环境并构建。

## 构建失败：卡在下载 Boost？

首次构建会自动解压并编译 Boost 1.89（约 150 MB），网络不通时容易卡住。可以手动把 `boost-1.89.0.tar.xz` 放到 `entry/src/main/cpp/`，或在能联网的环境预解压好 `boost/` 目录再拷过去——构建脚本检测到该目录存在就会跳过下载。

该缓存目录不入库，换机器需要重新准备一次。

## 构建失败：librime 相关文件找不到？

子模块没拉全。这个工程有 7 个子模块，且 librime 里的 deps 是嵌套子模块：

```bash
git submodule update --init --recursive
```

拉取中断过的话，工作目录可能留下空壳（缺 `HEAD`），需要同时删掉工作目录与 `.git/modules` 里对应项后重来。

## 构建成功但装不上真机？

产物是 **unsigned hap** 时无法安装。检查 `signing/signing.local.json5` 是否存在——它不入库，需要在本机按自己的证书配置一次，`hvigorfile.ts` 会在构建时把它注入。

另外自签名调试包必须使用**带 `data-group-id` 字段的签名 Profile**，否则设置页与输入法扩展无法共享数据（表现为设置页改动键盘读不到）。

## 安装后输入法列表里没有？

```bash
hdc shell ime -l
```

- 列表里没有 `com.kingzcheung.ximeharmony`：确认 hap 装的是签名版本，`hdc shell bm dump -n com.kingzcheung.ximeharmony` 能查到应用；
- 有但未启用：在「设置 → 系统 → 输入法」里手动启用；
- 都正常但输入框里调不出来：重启一次设备，或重新切一次输入法。

## 怎么切换到曦码输入法？

三种方式，习惯哪个用哪个：

1. 键盘上**长按地球键** → 打开键盘内的「选择输入法」页，点选目标输入法；
2. 键盘菜单第二页 →「选择输入法」；
3. 系统「设置 → 系统 → 输入法」里切换默认输入法。

只装了一个输入法时，选择页会提示「没有其他已启用的输入法」。

## 打字时编码去哪了？

鸿蒙版把编码**预上屏到应用编辑框内**（系统 `setPreviewText`），不在键盘上方画气泡。这是平台限制导致的调整：输入法面板窗口无法设透明，悬浮编码气泡做不出来，所以改成与华为系统键盘一致的形态。

不喜欢的话可以在「设置 → 布局与显示」里关掉编码显示。

## 修改了方案 / 主题，为什么没生效？

- **方案、词典、`xime.custom.yaml`**：必须部署。键盘菜单第二页点「部署方案」，或设置页「输入方案 → 部署」，等几秒生效。
- **主题、按键效果、键盘高度**：设置页保存后重新弹出一次键盘即可。设置页与扩展分属两个进程，键盘不会实时刷新。
- 部署失败看 `hdc shell hilog`（过滤 `XimeRimeConfig`）与沙箱里 `rime/build/*.log`。

## 为什么没有扩展商店 / 插件？

移植期明确不集成插件体系：`librime-lua`、`octagram`、`predict` 都不参与构建。因此没有 Lua 插件运行时，也就没有扩展商店入口。

代价是个别上游方案里用到 `lua_filter` 的功能会失效（日志出现 `error creating filter: 'lua_filter'`），但方案的直输、候选与词库都正常，属于预期降级。

## 支持手写输入吗？

不支持。鸿蒙侧目前没有可用的手写识别引擎，方案列表里也不启用 handwriting。手写、手写反查五笔编码这些能力只在 [Android 版](/features/handwriting)提供。

## 剪贴板是空的 / 没有振动 / 语音不可用？

先确认输入法是不是处在**基础访问模式**。该模式下系统会管控扩展进程：禁网络、禁剪贴板、禁振动与扬声器。表现为键盘能用但剪贴板面板为空、按键无反馈、语音入口置灰。

在系统设置里把输入法切到完整模式（不同 HarmonyOS 版本的入口名称略有差异）后重新弹出键盘即可。

## 候选栏里出现的剪贴板内容怎么没了？

候选栏的剪贴板条目有 **30 秒窗口**：只在复制后 30 秒内出现，点选过或超时都会自动收回。这是有意设计，避免旧内容长期挂在候选栏上误触上屏。

需要更早的内容时，用键盘菜单里的「剪贴板」面板，那里是完整历史。

## 设备互联配对好了，剪贴板还是不过去？

分三步看：

1. **开关**：设备互联页顶部的「启用局域网直连同步」是否打开。配对只建立信任，这个开关才是通道。
2. **模式**：系统「设置 → 系统 → 输入法」里是否给了完整体验模式。基础访问模式下扩展进程禁网络、禁剪贴板。
3. **生效时机**：配对完成后需要重新弹出一次键盘，已在运行的节点才会去连新设备。

设备互联页的「存储位置」如果显示「本机沙箱（不可跨进程）」，说明签名 Profile 缺少 `data-group-id`，配对表输入法读不到，功能不会生效。完整步骤见[手机端（鸿蒙）](/device-link/harmony)。

## 数据在哪？怎么备份？

Rime 数据在输入法扩展的沙箱目录 `files/rime/` 下，UI 设置在 `preferences` 里，两者都不在用户可见的公共目录。

- **用户词典**：设置 → 词库管理 → 导出
- **方案**：设置 → 输入方案 → 从文件导入 / 无线导入，重新导入已备份的方案包
- 卸载应用会连同沙箱数据一起清除，卸载前先导出

## 和 Android 版有什么区别？

同为手机版，但鸿蒙版是按平台重写的移植：

| 能力 | Android | 鸿蒙 |
|------|:-------:|:----:|
| 五笔 / 拼音方案、候选、部署 | ✅ | ✅ |
| 剪贴板、快捷发送、表情、语音 | ✅ | ✅ |
| 主题、键盘调节、悬浮、单手模式 | ✅ | ✅ |
| 插件体系与扩展商店 | ✅ | — |
| 手写输入 | ✅ | — |
| 智能联想 / 纠错 | ✅ | ✅ |
| 编码显示形态 | 候选栏气泡 | 编辑框预上屏 |

更细的对照见[功能文档](/features/)。

## 在哪里反馈问题？

鸿蒙版未公开分发，问题请直接反馈给开发者，附上：

- 设备型号与 HarmonyOS 版本（`hdc shell param get const.product.model`、`hdc shell param get const.ohos.apiversion`）
- 复现步骤：哪个应用、什么按键、预期与实际
- `hdc shell hilog` 里相关时间段的日志（过滤 `XimeRimeConfig` / `XimeInputMethod`）
