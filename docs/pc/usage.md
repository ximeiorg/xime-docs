# 桌面版（曦码·曜）

> 平台：桌面版 —— 当前提供 Windows 预览版（0.3.1 Beta），Linux / macOS 即将支持。各桌面平台体验大体一致，平台操作差异在文中以标签页区分。

曦码·曜（Xime Yao）是 Xime 的桌面版，与手机版共用同一套 Rime 生态（librime 内核、方案与词典格式通用）。桌面版与手机版是独立的产品：设置程序、启用方式、数据目录都不相同，**用户数据不共用**。

> [!WARNING]
> 当前为 Beta 预览版，官方仓库明确「请勿用于生产环境」。尝鲜前请先备份 `%APPDATA%\xime`（Windows）。

## 启用与切换

以下为 Windows 预览版的操作方式，Linux / macOS 发布后在此补充平台差异。

- 安装后在任意输入框按 `Win + Space`（或点击任务栏输入法指示器）切换到「曦码·曜」。
- 中文/英文：`Shift` 单击，或 `Ctrl + Space`；也可以点击托盘图标或候选栏面板切换。

## 托盘与候选栏

托盘右键菜单：

- **切换中/英**、**输入法设置**、**用户资料同步**、**关于**、**反馈**、**退出**
- **方案开关**：当前方案提供的可切换状态（如五笔拼音混输、简入繁出等），随方案动态显示

候选栏左侧 Logo 打开面板，包含 **剪切板 / 快捷发送 / 表情 / 符号 / 语音输入 / 设置**。候选词支持鼠标点击上屏（悬停有高亮与手型光标）；候选翻页使用方案自带的按键（默认 `↑` / `↓`），也可用滚轮。

## 设置程序

设置程序与手机版不是同一套界面，桌面版实际包含以下页面：

| 页面 | 用途 |
|------|------|
| 输入方案 | 方案来源、安装/卸载、导入方案、内置清理与恢复、部署 |
| 词典 | 用户词典与快捷短语：增删词条、导入导出文本、备份/恢复快照 |
| 外观 | 浅色/深色/跟随系统、配色、字号、候选词数量、圆角；撤销/恢复配置 |
| 快捷键 | 中英切换等按键说明；「重新部署」入口 |
| 扩展商店 | 方案、模型、插件、布局的下载与安装 |
| 插件管理 | 启用/停用、配置、卸载插件 |
| 语音转文本 | 本地语音模型下载、试听 |
| 剪贴板 | 剪贴板历史、快捷发送、剪贴板同步插件 |
| 同步与备份 | 备份服务（如 WebDAV）与备份/恢复 |
| 关于 | 版本信息 |

## 与手机版的差异

| 能力 | 手机版 | 桌面版 |
|------|---------|---------|
| 安装与启用 | 安装 APK，在系统设置中启用输入法 | MSI/MSIX 安装，`Win + Space` 切换 |
| 方案管理 | 「已导入」页 + 启用开关 | 已安装 / 已下载 / 方案词表三个标签，内置方案可清理与恢复 |
| 部署方案 | 功能菜单「部署方案」 | 输入方案页「部署方案」、快捷键页「重新部署」 |
| 计算器 | 数字键盘内置 | `=` 前缀计算器（见下节） |
| 语音转文本 | 本地模型 + 在线识别插件 | 本地模型（GPU 版可加速），无需联网 |
| 剪贴板 / 快捷发送 | 键盘面板 | 候选栏面板、设置程序 |
| 扩展商店 / 插件 / 云备份 | 支持 | 支持（与手机版插件通用） |
| 触屏键盘能力 | 键盘调节、悬浮键盘、九键、手写、智能纠错、工具栏定制 | 无（使用系统键盘布局与实体键盘） |

桌面版的方案列表里可以看到「拼音九键」「手写输入」等方案条目，但桌面端**没有**对应的触屏九键键盘与手写识别界面，选择它们不会得到手机上的输入方式。

## 计算器

中文输入状态下按 `=` 进入计算器，候选栏实时显示结果，支持鼠标点选与方向键切换。详见[计算器](/features/calculator)。

## 常见问题与排障

- **候选栏不出现 / 设置打不开**：先看 `%APPDATA%\xime\logs\server.log`；确认后台服务在运行，必要时重启系统或重新安装。
- **语音不可用**：在「设置 → 语音转文本」确认模型已下载；GPU 版缺少 CUDA / cuDNN 时会回退 CPU，日志中会有提示。
- **输入法列表里没有「曦码·曜」**：注销或重启后再按 `Win + Space`；仍没有则重新运行安装程序完成 TSF 注册。

更多问题见[常见问题](faq.md)，方案相关操作见[输入方案](input-scheme.md)。
