# 常见问题（桌面版）

> 平台：桌面版（曦码·曜）。当前内容以 Windows 预览版为准，Linux / macOS 即将支持。

## 安装与启用

### 怎么启用和切换「曦码·曜」？

安装 MSI / MSIX 后，按 `Win + Space` 选择「曦码·曜」；如果列表里没有，注销或重启一次。中英文用 `Shift` 或 `Ctrl + Space` 切换，也可以点托盘菜单切换。

### 卸载会删掉我的方案和设置吗？

不会。常规卸载只删除程序目录与输入法注册，`%APPDATA%\xime` 里的方案、词典和设置会保留，重装后可以继续使用。需要彻底清理时再手动删除该目录。

### 数据存在哪里？

`%APPDATA%\xime\`：`rime\` 是方案、词典与用户配置，`logs\` 是日志，`models\` 是语音等模型，`market\` 是已下载的方案包（`market\builtin\` 为内置方案备份），另有 `clipboard.db`（剪贴板历史）。迁移时复制整个目录即可。

## 方案

### 内置了哪些方案？

安装包自带 9 个方案：五笔86、五笔98、五笔拼音、简入繁出、拼音混输繁体、简体拼音、拼音九键、手写输入、大写数字；默认启用其中 5 个（五笔86、五笔拼音、简入繁出、拼音混输繁体、简体拼音）。

### 怎么导入自己的方案包？

「设置 → 输入方案」→ 右上角「导入方案」，可以拖入 `.zip` / `.tar.gz`、填本地路径或远程 URL，也可以直接从剪贴板读取文件或链接；导入后点「部署方案」生效。详见[输入方案](input-scheme.md#导入方案)。

### 切换方案后没生效？

在「输入方案」页点击方案行即可切换；若该方案还没有部署产物，会先提示「正在部署，请等待」，部署完成后自动切换。也可以手动点右上角「部署方案」。

### 为什么方案列表里有「拼音九键」「手写输入」却用不了？

这两个方案条目在 Windows 端没有对应的触屏九键键盘与手写识别界面，选择它们不会得到手机上的输入方式。

## 计算器

### 怎么用计算器？

中文输入状态、没有正在组词时按 `=`，输入算式后空格 / 回车 / `=` 上屏；候选可用鼠标点选或用方向键切换。详见[计算器](/features/calculator)。

### 直接打数字为什么先进了计算缓冲？

计算器的「数字自动识别」默认开启。可在 `%APPDATA%\xime\rime\xime.custom.yaml` 中写入 `calculator: { auto_detect: false }` 关闭。

## 排障

### 候选栏不出现 / 设置打不开

先看 `%APPDATA%\xime\logs\server.log`；确认后台服务在运行，必要时重启系统或重新安装。

### 语音不可用

在「设置 → 语音转文本」确认模型已下载；GPU 版缺少 CUDA / cuDNN 运行库时会自动回退 CPU，日志中会有提示。
