# 功能指南

## 手写输入

Xime 支持通过虚拟方案的方式实现手写输入，需在「输入方案」中启用手写方案并下载模型后方可使用：

- **手写识别** - 在手写区域直接书写，系统实时识别为文字
- **笔画动态变化** - 根据书写速度动态调整笔画粗细，书写更自然
- **手写查找** - 手写后反向查询对应编码（如五笔字根），辅助学习
- **候选注释** - 手写候选词支持注释信息显示
- **候选高亮** - 自动高亮首个推荐候选词，点击即可选择
- **主题色适配** - 手写键盘自动适配当前主题颜色，与键盘整体风格统一（v2.5.0+）
- **独立模型** - 使用独立的 ONNX 手写识别模型
- **启用方式** - 在输入方案中启用「手写输入」方案并部署，在 AI 模型管理中下载手写模型

详细说明请参考 [手写输入](features/handwriting.md)。

## 九宫格拼音（T9）

Xime 支持九宫格拼音（T9）输入模式，提供便捷的拼音输入体验：

- **九宫格键盘** - 经典的 3×4 九宫格布局，每个按键对应多个拼音字母
- **智能组词** - 基于 Rime 引擎的智能拼音组词
- **分词键支持** - 支持分词键（'）手动分隔音节
- **横屏分体式布局** - 横屏时左侧候选面板 + 右侧九键键盘，充分利用横屏空间（v2.5.0+）
- **数字键盘对齐** - T9 键盘与数字键盘底部行按键宽度对齐，切换无闪烁

> T9 九宫格拼音功能由社区贡献者 [@minilulubai](https://github.com/minilulubai) 开发。

## 语音转文本

语音转文本功能通过在线 FunAsr 插件支持通过麦克风进行实时语音识别：

- **在线实时识别** - 基于阿里百炼 FunAsr 插件，实时流式识别
- **整句提交** - 部分结果实时预览，句子结束（或长按松开）时一次性提交完整句子，连贯不重复
- **自带标点** - FunAsr 识别结果自带标点，宿主不再重复追加（可选标点预测模型进一步提升）
- **预缓冲机制** - 按住空格键时立即开始录音，防止语音丢失（吃字）
- **STT 开关** - 可在设置中启用或禁用语音转文字功能

详细说明请参考 [语音转文本](features/speech-to-text.md)。

## 输入方案管理

输入方案管理允许用户添加、切换和管理不同的输入方案：

- **方案列表** - 显示已启用和未启用的方案，支持开关切换
- **多种导入方式** - 支持文件选择、无线导入（浏览器上传）、URL 网络导入
- **方案版本选择** - 方案市场支持选择特定版本下载，方便体验不同版本特性
- **嵌套目录支持** - 支持导入雾凇拼音等包含子目录结构的方案包
- **Apple Double 过滤** - 自动过滤 macOS 系统产生的 `__MACOSX/` 和 `._` 前缀资源文件
- **下载优化** - 支持下载时唤醒锁管理，防止设备休眠中断下载
- **方案切换** - 键盘菜单栏只显示已启用且已编译的方案
- **部署生效** - 修改后需部署方案生效

详细说明请参考 [输入方案](features/input-scheme.md)。

## 剪贴板管理

剪贴板功能自动保存复制的内容：

- **剪贴板标签** - 查看所有复制历史
- **快捷发送标签** - 查看收藏的内容
- **文本拆分** - 将剪贴板文本拆分为单个字符，逐字选择输入
- **滑动操作** - 滑动显示拆词、快捷发送和删除选项
- **添加到快捷发送** - 将内容收藏到快捷发送
- **删除/清空** - 删除单条记录或清空所有历史

## 快捷发送

快捷发送功能允许用户收藏常用的文本内容，以便快速输入：

- **添加内容** - 在剪贴板标签中点击星形图标添加到快捷发送
- **表单编辑** - 直接在快捷发送列表中编辑内容，支持添加新条目和修改已有条目（v2.5.3+）
- **快速发送** - 在快捷发送标签中点击内容即可插入
- **管理收藏** - 删除不需要的收藏内容
- **永久保存** - 收藏的内容会一直保留，不会被新复制的内容覆盖

## 键盘调节

键盘调节功能允许用户根据个人习惯调整键盘的外观和尺寸：

- **高度调整** - 拖动键盘上方的控制条来改变键盘高度
- **横竖屏独立** - 横屏和竖屏可分别设置不同的键盘高度
- **底部间距调整** - 调整键盘与屏幕底部的间距，支持负值缩减固定空白区域
- **默认高度** - 一键恢复到默认高度设置
- **确认保存** - 调整完成后点击确认按钮保存设置

## 悬浮键盘

Xime 支持悬浮（浮动）键盘模式，让键盘以悬浮窗口的形式显示在屏幕中：

- **自由拖拽** - 悬浮键盘可自由拖动到屏幕任意位置
- **边界限制** - 悬浮窗口有坐标边界限制，防止移出屏幕
- **高度自适应** - 自动适配状态栏和导航栏高度
- **触摸优化** - 优化的触摸区域计算逻辑，交互更准确
- **横竖屏适配** - 横屏模式下自动调整悬浮位置和尺寸
- **一键切换** - 通过工具栏按钮快速切换悬浮模式

## 表情

表情功能提供丰富的表情符号和自定义表情插件：

- **内置表情** - 包含笑脸、手势、动物、食物等分类的表情符号
- **表情插件** - 支持扩展表情插件，添加颜文字、表情包等
- **多标签页** - Emoji 和插件分类标签页切换
- **主题适配** - 自动适配深色/浅色主题
- **分类浏览** - 按类别浏览表情，便于查找
- **快速插入** - 点击表情即可插入到输入框中

## 计算器

数字键盘内置计算器功能，支持数学表达式计算：

- **四则运算** - 支持加、减、乘、除运算
- **实时计算** - 输入表达式后自动计算结果
- **结果上屏** - 点击结果直接插入到输入框

## 工具栏自定义

工具栏位于候选栏左侧，用户可自定义按钮布局：

- **自定义按钮** - 选择在工具栏中显示的快捷按钮
- **分页菜单** - 菜单项分页显示，横竖屏自适应布局
- **按压反馈** - 按钮按压状态背景色和透明度反馈

## 删除键

### 点按优先级

删除键（退格键）点按时按以下优先级处理：

1. **联想词存在** — 清空联想词，不执行实际删除
2. **候选栏显示复制内容** — 清除候选栏的复制内容显示，不删除剪贴板中的实际内容
3. **英文待上屏** — 删除最后一个待上屏英文字符
4. **候选词/编码中** — 删除拼音编码
5. **已上屏文本** — 删除输入框中的文字

> 删除键不会触发联想词查询，仅用于删除操作。

### 滑动手势

删除键支持多种滑动手势，提供便捷的文本操作功能：

- **上滑清空** - 从删除键向上滑动，出现「上滑清空」提示后继续上滑，标签变红 ⚠️ 时松手即可清空输入框所有内容（包括已上屏的文字和编码）
- **下滑撤回** - 从删除键向下滑动，出现「下滑撤回」提示后继续下滑，标签变蓝 ℹ️ 时松手即可恢复上次被清空的内容
- **左滑清空编码** - 从删除键向左滑动，直接清空当前输入的编码（不删除已上屏的文字）
- **长按连续删除** - 长按删除键可连续删除文字

> 上滑清空和下滑撤回需要滑动较远距离才会触发，滑入红色/蓝色区域后如果反悔，滑回安全区域再松手即可取消操作，有效防止误触。

## 光标移动

在未打字时（候选栏为空），在全键盘或数字键盘上左右滑动可左右移动输入框中的光标：

- **右滑** - 光标右移，持续滑动可连续移动
- **左滑** - 光标左移，持续滑动可连续移动

## 部署方案

部署方案功能用于重新加载和应用输入方案配置：

- **重载配置** - 重新加载当前的输入方案配置
- **增量部署** - 首次启动时编译词库，后续仅刷新注册表，速度更快
- **应用更改** - 在切换输入方案或修改设置后需要重载配置
- **等待时间** - 重载过程需要几秒钟，大词库可能需要数分钟

## 词库管理

Xime 提供两套词库管理功能：个人词库和自定义短语。

- **个人词库** - 按输入方案隔离的个人词典。每个方案有独立的词库文件，通过 Rime 的 packs 或 import_tables 机制编译。词条编码需要符合方案编码规则（拼音用拼音、五笔用五笔字根）。
- **自定义短语** - 全局共享的短语，使用独立的 table_translator（stabledb）运行期读取。任意编码都可用，无需编译，适合邮箱、网址、简写等跨方案通用的内容。

详细说明请参考 [词库管理](features/dictionary.md)。

## WebDAV 同步

WebDAV 同步功能支持通过 WebDAV 协议备份和恢复输入方案配置与用户数据：

- **双向同步** - 支持上传到服务器和从服务器下载
- **全量备份** - 备份输入方案、词典、用户配置
- **多设备共享** - 在多台设备间同步相同的输入方案配置

详细说明请参考 [WebDAV 同步](features/webdav-sync.md)。

## 深色模式

支持三种显示模式：

- **浅色模式** - 始终使用浅色主题
- **深色模式** - 始终使用深色主题
- **跟随系统** - 自动跟随系统主题设置

状态栏外观也会同步跟随应用主题。

## 智能联想

Xime 内置智能联想词功能：

- **双引擎** - 中文联想基于 ONNX 模型，英文联想基于 Trie 树
- **用户学习** - 记录用户输入习惯，个性化联想结果
- **离线运行** - 模型下载后无需联网即可使用

详细说明请参考 [智能联想](features/smart-prediction.md)。

## 全键盘配置

> **版本要求**：此功能需要 Xime **v2.4.0 及以上版本**。

Xime 支持通过 `xime.custom.yaml` 配置文件自定义 26 键全键盘的按键布局、手势操作和外观样式（请勿直接编辑 `xime.yaml`）：

- **按键手势** - 为每个按键独立配置点按、上滑、下滑、长按四种手势
- **动作系统** - 支持上屏文本、剪贴板操作（复制/粘贴/剪切/全选）、光标跳转、内置命令等
- **长按气泡** - 长按按键弹出多个选项，左右滑动选择
- **字根显示** - 下滑按键显示五笔字根（气泡模式或按键模式）
- **配色方案** - 自定义主题色，内置多套预设配色
- **快捷键层** - 支持将下滑手势映射为文本编辑快捷键（全选、剪切、复制、粘贴、段首、段尾）

详细说明请参考 [全键盘配置](features/keyboard-config.md)。
