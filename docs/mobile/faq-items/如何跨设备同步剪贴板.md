剪贴板同步有两种方式，按网络环境选择：

**同一 Wi-Fi：设备互联（推荐）**

在同一局域网内与电脑直连，不经过任何服务器：

1. 手机进入「设置 → 数据与同步 → 设备互联」，与电脑配对（6 位配对码，60 秒内有效）
2. 打开「设置 → 数据与同步 → 剪贴板」中的「剪贴板同步」总开关
3. 进入「剪贴板同步 → 同步通道」，勾选「局域网直连」
4. 在电脑端 ximed 的「同步通道」中同样选择「局域网直连」并保存

手机端只同步纯文本，详细步骤与排查见 [设备互联](/device-link/)。

**跨网络：同步插件**

安装「WebDAV 剪贴板同步」插件，配置同一 WebDAV 账号即可在多台设备间双向同步剪贴板文本与图片，配置方式见下方视频演示：
