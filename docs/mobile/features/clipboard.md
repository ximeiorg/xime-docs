# 剪贴板管理

剪贴板功能自动保存复制的内容，方便用户快速调用历史记录。

## 功能特性

- **自动保存** - 复制的文本会自动保存到剪贴板历史（v2.6.0 起基于 Room 数据库本地存储）
- **图片剪贴板**（v3.0.0+） - 复制的图片自动捕获保存，候选栏与剪贴板统一展示、点击插入
- **拖拽发送**（v3.2.0+） - 长按条目后拖出，可直接把文本或图片拖拽发送到其他应用（如 QQ/TIM 的聊天输入框），弥补部分应用不支持直接粘贴图片的场景
- **分类查看** - 通过“剪贴板”和“快捷发送”两个标签管理
- **文本拆分（分词）** - 将剪贴板文本拆分为单个字符，逐字选择输入
- **快捷发送** - 收藏常用内容到快捷发送，永久保存
- **滑动操作** - 在项目上滑动显示拆词、快捷发送、删除等操作选项
- **批量管理** - 支持删除单条记录或清空全部历史
- **多设备同步**（v2.6.0+） - 通过剪贴板同步插件在多台设备间同步剪贴板内容（文本与图片）；同一 Wi-Fi 下还可以用「设备互联」与电脑直连，同步纯文本且不经过服务器

## 使用方法

1. 点击键盘上的 Logo 按钮打开功能菜单
2. 选择“剪贴板”进入剪贴板界面
3. 在“剪贴板”标签查看所有复制历史，在“快捷发送”标签查看收藏内容
4. 点击条目可直接插入到输入框
5. **滑动操作**：在条目上左右滑动，可显示操作面板（拆词、快捷发送、删除）
6. **拖拽发送**（v3.2.0+）：长按条目后拖出，可发送到其他应用，详见下方「拖拽发送」
7. 点击星形图标可将内容添加到快捷发送
8. 点击删除图标可移除单条记录

## 文本拆分（分词）

文本拆分功能可将剪贴板中的一段文本按字符拆分为单个字，方便逐字选择输入：

1. 在剪贴板列表中，在需要拆分的条目上滑动
2. 点击“拆词”按钮
3. 进入分词视图，每个字符独立显示
4. 点击单个字符即可输入，点击删除可移除
5. 点击“发送”将选中的字符一次性提交

## 图片剪贴板（v3.0.0+）

复制图片时会自动捕获并保存到本地剪贴板历史：

- **内容寻址存储** - 图片以 SHA-256 哈希命名，相同内容的图片自动去重
- **配额管理** - 图片数量、单张大小与总容量均有限制，可在设置中调整
- **隐私保护** - 敏感剪贴板内容（如密码管理器复制的条目，带系统敏感标记）默认不会被保存；如确需记录，可在「设置 → 剪贴板」开启「记录敏感内容」（v3.3.0+，开启时会提示风险）
- 候选栏中图片与文本条目统一处理，点击即插入

## 拖拽发送（v3.2.0+）

通过 Android 系统跨应用拖拽通道，把剪贴板条目直接“拖”进其他应用的输入框——很多应用（如 QQ/TIM）不支持直接粘贴输入法提供的图片，但都支持系统拖拽发送。

### 手势说明

| 操作 | 效果 |
| --- | --- |
| 长按条目后**直接抬起** | 弹出原有长按菜单（拆词 / 快捷发送 / 预览 / 删除等） |
| 长按条目后**拖出** | 进入拖拽发送：键盘自动收起，条目以拖影跟随手指 |
| 拖到目标应用输入框**松手** | 内容发送到该应用 |

### 说明

- **支持内容** - 文本条目与图片条目均可拖拽；“快捷发送”标签的条目同样支持
- **图片不进相册** - 图片通过应用私有文件共享（FileProvider）授权目标应用临时读取，不会写入系统相册
- **长按与拖拽并存** - 长按后原地松手仍是原来的菜单，只有明显拖出才进入发送；长按前的滑动仍用于滚动列表
- **多选模式下禁用** - 多选是为了批量管理，此状态下拖拽不生效
- **发送范围** - 目标应用需在其界面上支持系统拖拽接收（QQ/TIM 的聊天界面已支持）；发送行为由目标应用决定

## 剪贴板同步

剪贴板同步支持两类通道，可以单独使用，也可以同时勾选：

| 通道 | 适用场景 | 说明 |
|------|----------|------|
| 局域网直连（设备互联） | 手机与电脑在同一 Wi-Fi | 不经过服务器，端到端加密；手机端仅同步文本；需要先配对 |
| 同步插件 | 跨网络、多设备、需要图片 | 通过 WebDAV、S3、ximed 等插件中转；能力取决于插件 |

### 局域网直连

1. 在「设置 → 数据与同步 → 设备互联」中与另一台设备完成配对（6 位配对码，60 秒内有效）。
2. 回到「设置 → 数据与同步 → 剪贴板」，打开「剪贴板同步」总开关。
3. 点击「剪贴板同步」进入内页，在「同步通道」中勾选「局域网直连」。
4. 在电脑端 ximed 的「同步通道」中添加「局域网直连」并保存。

配对只建立信任关系，不会自动开始同步；总开关与通道都要打开。手机端只同步纯文本，详细说明与排查见[设备互联](/device-link/)。

### 同步插件

1. 在「扩展商店 → 插件」中下载并启用剪贴板同步插件（如「WebDAV 剪贴板同步」「S3 剪贴板同步」）
2. 在插件的配置表单中填写同步服务信息（如 WebDAV 地址、账号与密码）
3. 在「同步通道」中勾选对应插件；安装了多个插件时，可在「同步服务」中选择当前使用的一个

### 工作机制

- **多通道，直连优先** - 通道按勾选顺序生效：先勾「局域网直连」再勾插件，直连才会是首选。直连作为首选时，掉线约 10 秒后自动改走插件，恢复稳定后自动切回
- **单通道写入** - 同一时刻只通过一条通道推送，避免同一内容被推两次或两端互相回写
- **去重与回声抑制** - 与上次推送相同的内容不会重复发送；同步引擎写回本地剪贴板的内容不会被再次当作新内容推送
- **拉取间隔可调**（v3.0.0+） - 插件可通过配置项 `pull_interval_seconds` 调整自动拉取间隔（1~600 秒，默认 30 秒），修改后即时生效；也可在设置中手动拉取
- **加密传输** - 支持加密 API 与加密传输，剪贴板内容不以明文形式暴露
- **网络授权** - 同步插件需联网，首次使用时请在插件管理中为插件声明的域名授权

## 注意事项

- 剪贴板历史仅保存在本地（Room 数据库与图片文件）；同步通道只同步当前剪贴板，不会上传历史
- Android 10 及以上系统限制后台读取剪贴板，仅在使用键盘时自动保存复制内容
