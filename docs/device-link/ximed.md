# 桌面端（ximed）

ximed 是设备互联的桌面端：一个常驻托盘的剪贴板同步应用，负责与手机或其他电脑配对，并在局域网内直接收发剪贴板。Windows、Linux、macOS 共用同一套界面。

![ximed 概览页](/ximed/overview.png)

> ximed 当前提供**桌面形态**（窗口 + 托盘 + 同步引擎）。独立 server 形态与 HTTP 通道已从界面隐藏，暂不提供配置入口。

## 第一次启动

打开后是一个左右分栏的窗口：左侧是页面导航，右侧是当前页面。没有单独的初始化向导，按下面的顺序配置即可：

1. 到 **设备** 页确认本机设备名，或先完成配对。
2. 到 **同步通道** 页添加「局域网直连」或 WebDAV。
3. 点击「保存并应用」。
4. 到 **概览** 页确认同步总开关与连接状态。

关闭窗口默认**隐藏到托盘**，进程继续运行；只有托盘菜单的「退出 ximed」才会真正结束。

## 界面

| 页面 | 作用 |
|------|------|
| 概览 | 同步方式、连接状态、同步总开关、已配对设备数、本机设备 |
| 同步通道 | 通道优先级与参数、同步内容范围、保存并应用 |
| 设备 | 本机身份、配对、已配对设备管理 |
| 剪贴板历史 | 最近同步的剪贴板内容，点击卡片展开全文 |
| 设置 | 数据目录、跳转同步通道、开机自启状态 |
| 关于 | 版本、功能说明、许可证与依赖 |

## 配对

进入 **设备** 页。这一页只做配对与设备管理，配对操作**立即生效**，不需要点「保存」；设备名则在「同步通道 → 局域网直连 → 设备名」中修改。

### 显示配对码

1. 在「配对」中选择 **显示配对码**。
2. 点击「生成配对码」，页面显示 6 位数字和倒计时，**60 秒内有效**。
3. 在另一台设备（手机或另一台电脑）上选择「输入配对码」，填入这组数字。
4. 配对成功后，对方会出现在「已配对设备」中。

过期后显示「已过期，请重新生成」，点击「换一个」即可；点击「取消」结束本次配对。

### 输入配对码

1. 切换到 **输入配对码**。
2. 填入另一台设备上显示的 6 位数字，点击「配对」。
3. 桌面端会在同一网络内寻找对方，最长等待 60 秒。

配对期间本机的同步节点会短暂暂停（配对与同步使用同一组端口），结束后自动恢复。

### 已配对设备

- 每台设备显示名称、设备标识前 8 位，以及最近一次连接地址。
- 点击「移除」删除信任关系，对方需要重新配对才能再次连接。
- 同一时刻只保持一条直连（剪贴板是单值资源）。配对多台时，节点会与其中一台建立连接。

## 选择同步通道

进入 **同步通道** 页。通道是一个**有序列表，从上到下依次尝试，第一个是首选**。

### 添加局域网直连

1. 点击「＋ 局域网直连」加入列表。
2. 点击「配置」，可修改本机设备名（对方配对时看到的名字）。
3. 用 ↑ / ↓ 调整优先级；「移除」把通道从列表删除。
4. 点击「保存并应用」。

「连通性 → 测试连接」对局域网直连只检查是否已有配对设备，**不代表对端当前在线**；实际连接状态以概览页为准。

### 添加 WebDAV

如果两台设备不在同一局域网，或需要经网盘中转，可以改用 WebDAV：

1. 点击「＋ WebDAV」。
2. 填写服务器地址（如 `https://dav.example.com/dav/ximed`）、文件名（两端必须一致）、用户名与密码。
3. 点击「保存并应用」。

WebDAV 的「测试连接」会发起真实请求，验证地址与凭据是否可用。

### 优先级与自动切换

- 首选直连时，直连掉线超过约 **10 秒** 会切到备用通道（前提是列表里还有备用通道）；直连恢复并稳定后自动切回（切回有最短驻留时间，避免来回横跳）。
- 如果首选是 WebDAV，则会一直使用 WebDAV，不会因为局域网可用而自动改走直连。
- 同一时刻只运行一条通道，不会双写。

## 同步内容

在「同步通道」页下半部分设置：

| 项目 | 说明 |
|------|------|
| 同步总开关 | 关闭后引擎空转，不推送也不拉取 |
| 推送 | 本机剪贴板变化时发送到对端 |
| 拉取 | 对端内容变化时下载并写回本机剪贴板 |
| 文本 | 允许同步纯文本 |
| 图片 | 允许同步图片；局域网直连单帧上限 1 MiB，较大的图片可能发送失败 |
| 单个文件 | 预留项，当前版本不会同步文件 |
| 大小上限（MB） | 超过上限的内容不上传，默认 10 MB |
| 收到内容时通知 | 下载到新内容时提示来源设备 |

修改后需要点击「保存并应用」。

> 与手机配对时，手机端只处理文本：电脑发过去的图片不会在手机上出现，手机也不会把图片发到电脑。两台电脑之间可以同步图片，但受 1 MiB 单帧限制；大图建议改用 WebDAV 通道。

## 托盘常驻

- 点击窗口关闭按钮 = 隐藏到托盘，同步继续运行。
- 托盘菜单固定三项：**显示主窗口**、**隐藏到托盘**、**退出 ximed**。
- Windows / Linux 下左键点击托盘图标也可显示窗口。
- 「退出 ximed」会停止同步并结束进程；需要继续同步时重新打开即可。

## 数据与配置

「设置 → 数据目录」显示当前配置与历史所在的目录，点击「打开」可直接在文件管理器中查看。

| 文件 / 目录 | 内容 |
|-------------|------|
| `ximed-client.toml` | 应用设置：通道顺序、WebDAV 参数、设备名、同步范围 |
| `client-history.db` | 本机剪贴板历史（只记录同步与本地捕获的内容） |
| `p2p/` | 本机设备身份与已配对设备表；删除后需要重新配对 |

默认数据目录是程序工作目录下的 `data`，具体路径以设置页显示为准。界面里的修改会自动写回配置文件；手工编辑配置后，重新打开应用或再次点击「保存并应用」生效。

设备身份与配对表都在 `p2p/` 中。**不要手工拷贝或合并不同机器的 `p2p/` 目录**：身份与私钥绑定，混用会导致配对关系失效。

## 限制

- 只支持**同一局域网**，不做 NAT 穿透；跨网络请用 WebDAV。
- 同一时刻只保持一条直连，适合个人一两台设备。
- 只同步当前剪贴板，不合并剪贴板历史。
- 手机端只有文本；图片仅在两台桌面端之间可用，且受 1 MiB 单帧限制。
- 暂不支持开机自启（设置页显示「未支持」）。
- 独立 server 形态与 HTTP 通道当前不提供界面配置。

## 安全

- 配对使用 6 位码 + SPAKE2，码不上网；连续错误与超时都会作废。
- 连接使用 Noise IK 协商会话密钥，内容端到端加密。
- 没有中转服务器，内容不经过第三方；剪贴板历史只保存在本机。
- 已配对设备可以收到你之后复制的内容，只与自己信任的设备配对。
