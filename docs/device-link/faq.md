# 设备互联常见问题

## 配对

### 生成配对码后，另一台设备找不到？

先确认两端在**同一个 Wi-Fi、同一个网段**，然后逐项排查：

- 关闭手机和电脑上的 VPN。VPN 可能把局域网流量带走，或阻止广播发现。
- 确认连接的不是「访客网络」。访客网络通常开启了客户端隔离，设备之间无法互访。
- 路由器若开启了 **AP 隔离**（无线隔离 / 客户端隔离），请在管理后台关闭，或换一个网络。
- 公司、学校、酒店的公共网络可能禁止设备互访，这种情况无法使用设备互联，请改用 WebDAV 同步插件。
- Windows 首次运行 ximed 时如果拒绝了防火墙提示，请到「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」中放行 ximed，并勾选专用网络。
- 两端都停留在配对界面，不要提前退出。

### 输入配对码提示失败？

- 配对码 **60 秒**后过期，过期需要对方重新生成。
- 连续输错 **3 次**，当前配对码立即作废；请重新生成后再试。
- 同一时间只能进行一场配对，对方正在配对时会提示忙。
- 检查两端是否在同一网络；跨网段时无法直接配对。

### 配对时同步会中断吗？

桌面端在配对期间会短暂暂停同步节点（配对和同步使用同一组端口），配对结束后自动恢复。配对本身只建立信任关系，不会改变同步开关。

### 可以手动填 IP 地址配对吗？

不需要，也不支持。配对码会通过局域网自动找到对方；找不到时应排查网络隔离或防火墙，而不是填 IP。

## 同步

### 已经配对成功，但剪贴板不同步？

按顺序检查：

1. **手机**：设置 → 数据与同步 → 剪贴板 → 「剪贴板同步」总开关是否打开。
2. **手机**：进入「剪贴板同步」→「同步通道」，是否勾选了「局域网直连」（或包含直连的通道组合）。
3. **电脑**：ximed →「同步通道」是否添加了「局域网直连」，并点击过「保存并应用」。
4. **电脑**：「同步总开关」「推送」「拉取」是否打开。
5. **手机输入法**是否已启用；设备互联依赖输入法服务，键盘没有使用时不会持续同步。
6. **电脑上的 ximed 是否还在运行**。关闭窗口只是隐藏到托盘，同步仍在；托盘菜单「退出 ximed」才会停止。
7. 复制的是否为**纯文本**。图片、文件不会通过手机端的直连同步。
8. 稍等几秒。手机端每 2 秒检查一次远端内容；刚打开键盘时需要先建立连接。

### 只能单向同步？

- 电脑 → 手机收不到：检查电脑的「推送」开关、手机端是否在处理文本、手机键盘是否打开。
- 手机 → 电脑收不到：检查电脑的「拉取」开关、手机「剪贴板同步」总开关与直连通道。
- 部分密码管理器会把剪贴板标记为敏感内容，默认会被输入法忽略（除非在剪贴板设置中开启「记录敏感内容」），这不是设备互联的问题。

### 手机复制后马上锁屏，电脑还能收到吗？

通常可以。手机端在复制时会立即推送；如果复制时尚未连接，节点会记住最近一条，连上后补发。但如果输入法进程被系统回收，补发内容也会丢失。

### 为什么图片和文件不同步？

- **手机端只同步纯文本**。通过局域网直连，图片和文件不会传输，也不会在电脑上生成占位内容。
- **两台电脑之间**可以同步图片，但局域网直连单帧上限为 1 MiB，较大的图片可能失败；大图建议改用 WebDAV 通道。
- 「单个文件」目前是预留项，当前版本不会同步文件。

### 会同步剪贴板历史吗？

不会。设备互联只同步**当前这一条**剪贴板内容，历史仍保存在各自设备本地，不会因为配对而互传。

### 多台设备能同时收到同一条内容吗？

可以配对多台设备，但剪贴板是单值资源，同一时刻只保持一条直连。需要多台设备同时同步时，建议使用 WebDAV 等同步插件，或把设备互联作为两台主力设备之间的通道。

## 网络与安全

### 两台设备不在同一个 Wi-Fi，能用吗？

不能。设备互联只做局域网直连，不做 NAT 穿透。跨网络、跨城市请使用 WebDAV 等同步插件。

### 需要开放哪些端口？

默认使用：

| 端口 | 协议 | 用途 |
|------|------|------|
| 47821 | TCP | 同步会话 |
| 47822 | UDP | 局域网发现 |
| 47823 | TCP | 配对 |

端口被占用时会顺延，因此最稳妥的做法是在防火墙中**按应用放行 ximed**，而不是只放行固定端口。手机端一般不需要额外设置。

### 内容会经过服务器吗？

不会。设备互联没有中转服务器，剪贴板内容只在两台已配对设备之间加密传输。配对码也不会出现在网络报文里。

### 在公共 Wi-Fi 上使用安全吗？

传输本身是端到端加密的，但公共网络可能存在 AP 隔离、强制门户或恶意热点，连接稳定性和可达性都无法保证。更重要的是**不要和自己不认识的设备配对**：已配对设备可以收到你之后复制的内容。

### 同一 Wi-Fi 下别人能偷看内容吗？

配对阶段使用 6 位码 + SPAKE2，码只通过屏幕和手动输入传递；连接阶段使用 Noise IK 协商会话密钥，内容端到端加密。攻击者即使抓包，也无法直接还原剪贴板内容。3 次错误上限和 60 秒有效期也限制了在线猜测。

### 开了 VPN 就连不上？

VPN 可能改变默认路由，使局域网广播和直连流量走隧道。请关闭 VPN，或在 VPN 中设置局域网直连 / 分应用代理后重试。

## 设备管理

### 换手机或重装应用后连不上？

设备身份由本机密钥派生，重装或清除应用数据后身份会变化。请在两端删除旧设备记录，然后重新配对。

### 怎么彻底删除配对关系？

在任意一端删除即可让信任关系失效：手机「设备互联 → 已配对设备 → 解除」，电脑「设备 → 已配对设备 → 移除」。删除后双方都需要重新配对才能连接。

### 桌面端关闭窗口后还同步吗？

同步。关闭窗口只是隐藏到托盘，进程仍在后台运行。只有托盘菜单「退出 ximed」或结束进程才会停止同步。

### 手机上的「ximed 剪贴板同步」插件和这里的设备互联是一回事吗？

不是。扩展商店里的「ximed 剪贴板同步」插件是另一种基于 HTTP 服务的同步方式；本页讲的是 ximed 桌面应用提供的**局域网直连**。两者都属于剪贴板同步通道，但传输路径不同，不要把它们当成同一个开关。

### 设备互联需要开蓝牙或定位吗？

不需要。它只使用 Wi-Fi / 局域网连接。Android 系统可能因为省电策略限制后台运行，必要时请把 Xime 加入电池优化白名单。

### 鸿蒙版和 macOS 版要装 ximed 吗？

不用。这两个平台自带直连节点：

- **鸿蒙**：在「曦码输入法」设置里进入 **设备互联**，配对与管理都在这里，节点跑在输入法扩展进程里。
- **macOS**：不需要 ximed，直连能力在 **曦码·逸输入法** 里，入口是设置程序的 **设备关联** 页。

它们和 ximed 用的是同一套协议，所以「鸿蒙 ↔ ximed」「曦码·逸 ↔ 鸿蒙」「曦码·逸 ↔ ximed」都能配对，混着用没问题。

### macOS 上设备关联配对成功，但剪贴板没同步？

配对只是建立信任，还需要到设置程序的 **剪贴板 → 剪贴板同步** 打开「局域网直连」开关。想同时用插件就把两个开关都打开：按勾选顺序决定优先级，首个优先，直连掉线会自动让位给插件。详细步骤见[桌面端（曦码·逸）](/device-link/ximeyi)。

另外确认输入法当前处于激活状态——直连节点跑在输入法进程里，没切到曦码·逸时不会维持连接。

### 鸿蒙版打开设备互联，配对入口是灰的或提示不可用？

先打开页面顶部的「启用局域网直连同步」开关——开关关闭时配对入口不可用。如果开关打开后仍然不工作，检查两点：

1. 系统「设置 → 系统 → 输入法」里，曦码输入法是否处于**完整体验模式**。基础模式下扩展进程没有网络与剪贴板权限。
2. 设备互联页的「存储位置」是否显示**共享沙箱**。显示「本机沙箱（不可跨进程）」说明签名 Profile 缺少 `data-group-id`，主 App 写入的配对表输入法读不到。

### 鸿蒙版配对成功但剪贴板不过去？

配对只建立信任，回输入框**重新弹出一次键盘**才会让扩展进程加载新的配对表并连接。仍不同步时确认：设备互联页的开关是否还开着；对端是否在线；是否同时开了其它剪贴板同步（鸿蒙版与 WebDAV 等通道互斥）。
