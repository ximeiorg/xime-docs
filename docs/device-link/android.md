# 手机端（Android）

Xime 手机版通过「设备互联」加入局域网直连。配对与设备管理在设置里完成，真正的剪贴板同步由输入法服务负责。

> 设备互联需要手机已启用 Xime 输入法，并且系统没有限制输入法后台运行。部分机型的省电策略会在锁屏或长时间未输入时回收输入法进程，回到键盘后会自动重连。

## 入口

有两条路径可以进入设备互联页面：

- **设置 → 数据与同步 → 设备互联**
- **设置 → 数据与同步 → 剪贴板 →「剪贴板同步」→ 设备互联**

第二条路径适合已经在配置同步的用户；第一条路径是配对的一级入口。

## 页面说明

| 区域 | 内容 |
|------|------|
| 本机 | 设备名称（配对时显示给对方，默认取机型名，可修改，最多 32 个字符）与设备标识（由本机密钥派生，只读） |
| 配对设备 | 「生成配对码」与「输入配对码」两种配对方式 |
| 已配对设备（N） | 已建立信任的设备列表，显示名称与标识前 8 位，可「解除」 |
| 说明 | 运行条件、同步时机、加密方式与通道降级说明 |

设备标识用于在两端对照确认是同一台机器。它不是账号，也不会上传；重装应用或清除数据后会变化。

## 配对

两台设备在同一 Wi-Fi 下，任选一个方向操作。

### 手机显示、电脑输入

1. 手机进入 **设备互联**，在「配对设备」中点击「生成配对码」。
2. 页面显示 6 位数字（按 `482 719` 分组），**60 秒内有效**。
3. 在电脑上打开 ximed → **设备** → **输入配对码**，填入这 6 位数字，点击「配对」。
4. 两端提示配对成功后，设备会出现在手机的「已配对设备」列表中。

如果 60 秒内没有完成，配对码会失效。点击「重新生成」换一组即可。

### 电脑显示、手机输入

1. 在电脑上打开 ximed → **设备** → **显示配对码** → 点击「生成配对码」。
2. 手机进入 **设备互联**，点击「输入配对码」。
3. 填入电脑上显示的 6 位数字，点击「开始配对」。
4. 等待期间保持两端的配对界面打开；成功后手机显示「配对成功：设备名」。

### 配对状态

| 状态 | 含义 |
|------|------|
| 等待对端输入配对码… | 手机已生成配对码，等待对方输入 |
| 配对成功：设备名 | 信任关系已建立，可以去开启同步 |
| 配对失败：原因 | 配对码错误、超时、对方取消或网络不可达 |
| 正在查找设备… | 手机已提交配对码，正在局域网内寻找显示该码的设备 |

- 连续输错 **3 次**，当前配对码立即作废，需要对方重新生成。
- 同一时间只能进行一场配对；已有配对进行中时，新的配对会提示忙。
- 配对只建立信任关系，**不会自动开启剪贴板同步**。

## 开启同步

配对完成后，还需要打开剪贴板同步并选中直连通道：

1. 进入 **设置 → 数据与同步 → 剪贴板**。
2. 打开「剪贴板同步」开关（总开关在这一页）。
3. 点击「剪贴板同步」整行进入内页。
4. 在「同步通道」中勾选 **局域网直连**。已配对时副标题会显示「已配对 N 台 · 优先」。
5. 如果同时安装了 WebDAV 等同步插件，先勾选「局域网直连」再勾选插件，让直连成为首选通道；离开局域网时会自动改走插件。

> 至少需要勾选一个通道。一个通道都没勾选时，页面会提示「至少勾选一个通道才能同步」，同步不会启动。
>
> 通道按勾选顺序决定优先级。已经先勾了插件、后勾直连时，插件会排在前面；此时取消全部勾选，按「先直连、后插件」的顺序重新勾选即可。

没有已配对设备时，直连节点不会启动，也不会占用端口。完成配对后，输入法服务会自动重启直连节点。

## 什么时候会同步

- **打开键盘时**：输入法服务启动直连节点，连接已配对设备，并拉取一次对方当前的剪贴板。
- **使用键盘期间**：本地复制会立即推送；远端变化每 2 秒检查一次，收到后写回系统剪贴板。
- **键盘收起后**：不在后台持续读取剪贴板（受 Android 系统限制），下次打开键盘时继续。
- **连上补发**：连接建立前复制的最后一条内容，会在连上后补发一次。

因此，「手机复制后马上在电脑粘贴」通常几秒内完成；如果手机刚打开键盘，可能需要等连接建立。

## 只同步文本

手机端的局域网直连**只同步纯文本**：

- 复制图片、文件不会通过直连传输，也不会在另一端生成占位内容。
- 文本同步不受影响；去重、回声抑制与重试仍按原有同步引擎执行。
- 如果同时启用了支持图片的同步插件，图片走插件通道，不走直连。

## 管理已配对设备

- **解除**：在「已配对设备」中点击设备右侧的「解除」，删除信任关系并重启直连节点；对方需要重新配对。
- **修改名称**：修改「本机 → 设备名称」后，后续配对会在对方设备上显示新名称；已配对设备上显示的名称不会追溯更新。
- **多台设备**：可以配对多台，但剪贴板是单值资源，同一时刻只保持一条直连。适合手机与一两台主力电脑配对；设备很多时建议只保留常用的几台。

## 排查

| 现象 | 可能原因与处理 |
|------|----------------|
| 页面顶部提示「P2P 原生库未加载」 | 当前安装包不包含设备互联能力，请安装官方完整版 APK |
| 生成配对码后对方找不到设备 | 确认两台设备在同一 Wi-Fi、同一网段；关闭 VPN；确认路由器未开启 AP 隔离或访客网络隔离 |
| 输入配对码后一直「正在查找设备…」 | 对方页面是否仍打开、配对码是否过期；桌面端是否被防火墙拦截 |
| 配对提示失败 | 配对码输错或已过期；连续错 3 次需重新生成；确认两端仍在同一网络 |
| 已配对但不同步 | 检查「剪贴板同步」总开关、通道里是否勾选「局域网直连」；手机输入法是否启用；桌面端 ximed 是否仍在运行 |
| 只能单向同步 | 检查桌面端的「推送 / 拉取」开关；手机端复制后需保持键盘打开几秒 |
| 锁屏一段时间后失效 | 系统省电策略回收了输入法进程，打开键盘会自动重连；必要时把 Xime 加入电池优化白名单 |
| 换手机或重装后连不上 | 本机身份已变化，需要在两端删除旧记录并重新配对 |

更多问题见[设备互联常见问题](/device-link/faq)。

鸿蒙版走的是同一套协议，入口在设置页的「设备互联」，没有插件通道，步骤见[手机端（鸿蒙）](/device-link/harmony)。
