# 桌面端（曦码·曜）

曦码·曜是 Windows 输入法，直连节点跑在后台服务 `winxime-server.exe` 里，不需要额外安装 ximed：配对入口在设置程序的「设备关联」页，同步开关在「剪贴板 → 剪贴板同步」。

> 节点随后台服务常驻：安装时注册的 `winxime-server.exe` 一直运行，关掉设置程序窗口不影响同步；只有托盘菜单「退出」结束服务后才会中断。

> 当前为 Windows 预览版，项目仍标注「请勿用于生产环境」。功能可用，但跨设备连通性、图片与旧版本互通仍在实机验证中。

## 打开设置程序

两种方式：

- 候选栏 ⋮ 菜单 →「设置」
- 任务栏托盘右键 →「设置」

设置程序侧栏的「同步与备份」分组下，设备互联用到两页：「设备关联」与「剪贴板」。

## 页面说明

「设备关联」页分三块：

| 区域 | 内容 |
|------|------|
| 本机 | 设备名（可编辑，点「保存」生效）与设备标识（由本机密钥派生，只读） |
| 配对 | 标签栏切换「显示配对码 / 输入配对码」，一次只显示一个方向 |
| 已配对设备 | 设备名与标识前几位，附「最近地址」或「尚未连接过」；右侧「移除」（需二次确认） |

设备名只用来让对方认出这台机器，建议写清是哪台，例如「书房 Windows」。设备标识用于两端对照确认是同一台机器，排障时用得上。

## 配对

两台设备连同一个 Wi-Fi，任选一个方向。配对码只经人眼传递，不会出现在网络报文里。

### 本机显示配对码

1. 「设备关联 → 显示配对码」→ 点「生成配对码」。
2. 页面显示 6 位数字与倒计时，**60 秒内有效**。
3. 在另一台设备（手机或另一台电脑）上输入这组码完成配对。
4. 过期后显示「已过期，请重新生成」；点「换一个」换一组，点「取消」立刻作废。
5. 连续输错 **3 次**，当前配对码立即作废，需要重新生成。

### 输入对方显示的配对码

1. 切到「输入配对码」，填入对方显示的 6 位数字（输入框提示为 `例如 482 719`）。
2. 点「配对」，按钮变为「正在查找设备…」，自动在同一 Wi-Fi 下发现对方，**最长等 60 秒**。
3. 成功后页面顶部显示状态条，设备出现在「已配对设备」里。

如果局域网广播被拦（AP 隔离、公司网络），展开 **手动地址** 填对方的 `192.168.1.5` 或 `192.168.1.5:47823` 再配对。

> 另一方向还在进行时，当前标签顶部会提示配对状态，避免误以为点击没生效而反复操作。

配对只建立信任关系，**不会自动开启同步**。配对会话走独立端口 `47823`，配对时同步照常进行。

## 开启同步

到 **设置 → 剪贴板 → 剪贴板同步**。这里是开关式多选，不是下拉选择：

| 开关 | 说明 |
|------|------|
| 局域网直连 | 与配对过的设备点对点传输，不经第三方服务器；副标题显示「已配对 N 台，不经过任何服务器」 |
| 同步插件 | 安装剪贴板同步插件后经 WebDAV 等通道跨网络同步；开关名称随已选插件变化 |

- **勾选即生效**：开关写入 `clipboard_sync.toml`，后台服务在下一个轮询节拍内重建同步线程，**不需要重启输入法**。
- **两个都勾是「自动」**：当前 Windows 实现是两条通道**同时推送**，靠内容 hash 去重，而不是「直连可用就只走直连」的主备切换。若只想走其中一条，请只勾对应开关。
- 只勾直连就只走直连，不会改用插件；两个都不勾时页面显示「同步已关闭」，剪贴板只留在本机。
- 还没有配对设备时，直连开关的副标题会提示「还没有已配对设备，先到『设备关联』配对」，旁边有「去配对」按钮直达配对页。

## 什么时候会同步

- 同步桥是后台服务里的**独立线程**，推送 / 拉取不会阻塞打字。
- 本地复制由系统剪贴板更新事件实时推送；远端内容约每 **30 秒**拉取一次。
- 关掉设置程序窗口不影响同步——节点在 `winxime-server.exe` 里；托盘「退出」结束服务才会中断。
- 收到后**直接写入系统剪贴板**，可以立刻 `Ctrl+V`，同时进入 `clipboard.db`，在候选栏「剪切板」面板里能看到这条记录。
- 只同步**当前剪贴板**，不会把历史整体上传；图片、文件不会通过直连传输（收到图片会记日志后跳过）。
- 每台设备的剪贴板历史上限 50 条，单条文本最多 2000 字符。

## 管理已配对设备

- **移除**：在「已配对设备」里点「移除」，会先要一次确认（「确认移除？」），确认后删除信任关系；对方需要重新配对。
- **改名**：改「本机 → 设备名」并点「保存」，下次配对或同步时告知对端；已配对设备上显示的旧名不追溯更新。
- **多台设备**：可以配对多台，但剪贴板是单值资源，同一时刻只保持一条直连。设备较多时建议只保留常用的几台。

## 数据与日志

| 路径 | 内容 |
|------|------|
| `%APPDATA%\xime\p2p\identity.bin` | 本机身份密钥，与设置程序共用同一份 |
| `%APPDATA%\xime\p2p\peers.json` | 已配对设备表 |
| `%APPDATA%\xime\p2p\device.json` | 本机设备名 |
| `%APPDATA%\xime\clipboard_sync.toml` | 同步通道配置（`enabled` + `channels`，首个优先） |
| `%APPDATA%\xime\clipboard.db` | 剪贴板历史 |
| `%APPDATA%\xime\logs\server.log` | 运行日志，搜 `局域网同步节点已启动` / `局域网直连` 可看到节点与收发情况 |

设置程序与后台服务必须指向同一用户目录，否则会出现「设置里配对成功、输入法仍认为未配对」。删除 `p2p/` 目录等于重置身份：所有旧配对都会失效，需要重新配对。

端口为 TCP `47821`（直连）、UDP `47822`（局域网发现）、`47823`（配对）；被占用时会自动向后顺延（最多探测 16 次），因此防火墙建议**按程序放行 `winxime-server.exe`**，不要只放行固定端口。

## 限制

- 只支持**同一局域网**，不做 NAT 穿透；跨网络请用 WebDAV 等同步插件。
- 只同步文本；图片、文件不会通过直连传输，WebDAV 插件目前也不能在桌面端落盘图片。
- 「自动」模式是双通道同时推送、靠 hash 去重，没有基于连接健康度的主备切换。
- 本机上配对输入端与常驻节点可能争用 UDP `47822`；跨设备配对不受影响，同机异常时可用「手动地址」兜底。
- 预览版状态：与旧版本客户端的互通、两机实机连通性仍在验证中。

## 排查

| 现象 | 可能原因与处理 |
|------|----------------|
| 配对成功但剪贴板不同步 | 「剪贴板 → 剪贴板同步」里的「局域网直连」开关没勾，配对不等于同步 |
| 生成配对码后对方找不到 | 同一 Wi-Fi、同一网段；关闭 VPN；路由器未开 AP 隔离；必要时用手动地址 |
| 输入配对码一直「正在查找设备…」 | 对方页面是否还开着、码是否过期（60 秒）；防火墙是否拦了后台服务 |
| 设置程序关掉后同步停了 | 不会。节点在 `winxime-server.exe` 里；真正会断的是托盘「退出」结束服务 |
| 收到内容但 `Ctrl+V` 是旧的 | 系统剪贴板写入失败，日志会有 `局域网直连收到远端剪贴板，但写回系统剪贴板失败` |
| 日志里反复出现端口占用 | 上一次后台服务异常残留，托盘退出后重启服务 |
| 移除设备后对方还能看到本机 | 需要在两端都移除；只在一端删，另一端仍保留旧配对记录 |

更多问题见[设备互联常见问题](/device-link/faq)，输入法本身的问题见[Windows 常见问题](/pc/faq)。
