# 设备互联

设备互联让**同一局域网（Wi-Fi）内的手机和电脑直接互传剪贴板**：手机复制，电脑粘贴；电脑复制，手机粘贴。配对一次后自动连接，全程不经过任何第三方服务器，内容端到端加密。

设备互联是「剪贴板同步」的一种传输通道，界面里叫**局域网直连**。它与 WebDAV 等同步插件并列：两者可以同时启用，优先走直连，离开局域网或对端离线时自动改走插件，回到局域网后自动切回。

## 能做什么

| 能力 | 说明 |
|------|------|
| 双向同步 | 两端复制的内容都会同步到对方剪贴板，文本为主 |
| 免服务器 | 设备之间直连，不依赖云盘、账号或中转服务 |
| 端到端加密 | 配对使用 6 位码，连接使用协商密钥，内容不在网络上明文传输 |
| 自动重连 | 配对过的设备在同一网络下自动发现并重连 |
| 与插件共存 | 可同时勾选直连与同步插件，按可用性自动切换 |
| 只在信任设备间同步 | 只有完成配对的设备才能连接，可随时解除 |

## 不能做什么

- **不能跨网络**：只适用于同一局域网。跨网络、跨运营商请使用 WebDAV 等同步插件。
- **不传剪贴板历史**：只同步「当前这一条」，历史仍留在各自设备本地。
- **手机端只同步文本**：受输入法剪贴板能力限制，手机通过局域网直连只同步纯文本；图片、文件不会通过这条通道传输。
- **需要设备在线**：手机端依赖输入法服务运行；桌面端要么是 ximed 保持运行（最小化到托盘即可），要么是装着输入法的应用本身在运行（macOS 的曦码·逸就是这种形态）。

## 支持范围

| 端 | 应用 | 入口 |
|----|------|------|
| 手机（Android） | [Xime 输入法](/mobile/usage) | 设置 → 数据与同步 → 设备互联 |
| 手机（鸿蒙） | [曦码鸿蒙版](/harmony/usage) | 设置 → 设备互联 |
| 桌面（Windows / Linux） | [ximed](/device-link/ximed) | 设备 → 配对 |
| 桌面（macOS） | [曦码·逸输入法](/ximeyi/usage) | 设置程序 → 设备关联 |

两端的配对协议一致，不分主从：一端显示配对码、另一端输入，或反过来都可以。

> 桌面端有两个载具：**ximed**（独立托盘应用，Windows / Linux 使用）与 **曦码·逸**（macOS 输入法内置的直连节点，不需要额外装 ximed）。两者用的是同一套 P2P 协议，可以与任意手机端（Android / 鸿蒙）配对，也可以互相配对。
>
> Linux 端的曦码·澈也提供了「设备关联 / 设备互传」入口，但该功能仍在开发中，暂未纳入本文的正式步骤。详见[曦码·澈使用与设置](/ximeche/usage#设备互传-开发中)。

## 前提条件

1. **两台设备连同一个 Wi-Fi**，并且处于同一网段。
2. 手机上已启用输入法（设备互联依赖输入法服务常驻运行）。
3. 桌面端已有节点在跑：Windows / Linux 启动 ximed；macOS 直接用曦码·逸，无需额外应用。最小化到托盘不影响同步。
4. 路由器未开启 **AP 隔离 / 访客网络隔离**，公司或校园网没有禁止设备互访。
5. 系统防火墙允许接收局域网连接（Windows 首次运行 ximed 通常会询问，请选择「允许」）。
6. 两端装的是包含设备互联的版本：手机端能在设置里看到「设备互联」入口，桌面端能在「设备」或「设备关联」页生成配对码。

## 快速开始

下面以「电脑显示配对码、手机输入」为例。反过来操作同样可以。

### 1. 在电脑上生成配对码

打开 ximed，进入左侧 **设备** 页，在「配对」中选择 **显示配对码**，点击「生成配对码」。

macOS 上不需要 ximed：打开 **曦码·逸输入法设置 → 设备关联**，点「生成配对码」即可。

页面会显示一组 6 位数字，**60 秒内有效**。过期后点击「换一个」重新生成。

### 2. 在手机上输入配对码

Android：打开 Xime 设置，进入 **数据与同步 → 设备互联**，点击「输入配对码」，填入电脑上显示的数字，点击「开始配对」。

鸿蒙：打开「曦码输入法」设置，进入 **设备互联**，同样点「输入配对码」并填入数字。

等待几秒，两端都会提示配对成功。手机页面底部会出现「已配对设备（1）」。

### 3. 开启同步

配对只建立设备之间的信任关系，**不会自动开始同步**。还需要分别在两端选择通道：

- **Android**：设置 → 数据与同步 → 剪贴板 → 打开「剪贴板同步」开关 → 进入「剪贴板同步」→ 勾选「局域网直连」（如果也用插件，先勾直连再勾插件）。
- **鸿蒙**：设置 → 设备互联 → 打开「启用局域网直连同步」。鸿蒙没有插件通道，这个开关同时也是通道开关。
- **Windows / Linux（ximed）**：同步通道 → 添加「局域网直连」→ 点击「保存并应用」→ 确认「同步总开关」已打开。
- **macOS（曦码·逸）**：设置程序 →「剪贴板」→「剪贴板同步」→ 打开「局域网直连」开关。两个开关都打开时按勾选顺序决定优先级，首个优先；只开直连就只走直连。

完成后，在任意一端复制文本，几秒内就能在另一端粘贴。手机端打开键盘时会自动连接并拉取一次当前剪贴板。

## 配对规则

- 配对码为 **6 位数字**，显示时按 `482 719` 分组，有效期为 **60 秒**。
- 配对码只在屏幕上显示，通过人眼和手指传递，不会出现在网络报文里。
- 连续输错 **3 次**，当前配对码立即作废，需要重新生成。
- 配对期间桌面端会短暂暂停同步节点（占用同一组端口），结束后自动恢复。
- 配对成功后两端对等，任一端都可以主动连接。
- 已配对设备可以随时「解除 / 移除」，移除后需要重新配对。

## 同步是怎么工作的

- **发现与连接**：已配对设备优先直连上次地址；地址变化时通过局域网广播重新发现。两端在同一网络时自动重连。
- **优先直连、插件兜底**：同时启用直连与同步插件时，直连是首选。直连掉线约 10 秒后切到插件；直连恢复并稳定后自动切回（切回有最短驻留时间，避免来回横跳）。
- **手机端的运行时机**：直连节点跑在输入法进程里。打开键盘后自动连接已配对设备，并每 2 秒检查一次远端内容；键盘未使用时不会在后台持续读取剪贴板。
- **桌面端的运行时机**：ximed 在后台持续工作，窗口关闭到托盘也不影响同步，只有托盘菜单「退出 ximed」才会停止；曦码·逸（macOS）的直连节点跑在输入法进程里，切换到这个输入法时建立连接。
- **连上补发**：如果本地保存着最近一次剪贴板内容，连接建立后会补发一次，避免「刚复制完才连上，对方收不到」。
- **单通道**：剪贴板同一时刻只走一条通道，不会双写。直连与插件互斥切换，不会同时推送。

## 安全与隐私

- **配对**：6 位码通过 SPAKE2 密钥交换强化，低熵的短码不会直接作为密钥；60 秒有效期与 3 次错误上限让在线猜测不可行。
- **传输**：连接使用 Noise IK 协商会话密钥，剪贴板内容端到端加密，每次连接重新协商。
- **不落云**：没有中转服务器，内容不经过任何第三方；剪贴板历史也不会因为设备互联而上传。
- **本地密钥**：设备身份由本机密钥派生，密钥只保存在各自设备的数据目录中。
- **信任边界**：已配对设备可以收到你之后复制的内容。只与自己控制的设备配对；在公共 Wi-Fi 上配对前请确认网络环境可信。

## 解除配对

- **Android**：设备互联 → 已配对设备 → 点击「解除」。
- **鸿蒙**：设备互联 → 配对设备 → 点击设备右侧「解除」。
- **Windows / Linux**：设备 → 已配对设备 → 点击「移除」。
- **macOS**：设置程序 → 设备关联 → 已配对设备 → 点击「移除」并确认。

解除后信任关系失效，对方需要重新配对才能再次同步。重装应用或清除应用数据也会丢失本机身份，需要重新配对。
