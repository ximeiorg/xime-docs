# 桌面端（曦码·逸）

macOS 上不需要额外安装 ximed：直连节点就跑在曦码·逸输入法进程里，配对入口在**曦码·逸输入法设置**的「设备关联」页。

> 节点是**进程级单例**：第一次有通道需要它时启动，之后跨通道切换一直存活，不会重复抢端口。所以切换同步通道不需要重启输入法。

## 打开设置程序

两种方式：

- 在候选窗菜单里点 **设置**
- 直接打开 `XimeYi.app/Contents/MacOS/XimeYiSettings.app`

设置程序与 Windows / Linux 共用同一份 `xime-setup` 代码，界面上的产品名由曦码·逸侧注入；「设备关联」页对应 ximed 里的**设备**页。

## 页面说明

| 区域 | 内容 |
|------|------|
| 本机 | 设备名（可编辑，点「保存」写入 `p2p/device.json`）与设备标识（由本机密钥派生，只读） |
| 配对 | 标签栏切换「显示配对码 / 输入配对码」，一次只显示一个方向 |
| 已配对设备 | 设备名与标识前几位，附「最近地址」或「尚未连接过」；右侧可「移除」 |

设备名只用来让对方认出这台机器，建议写清是哪台，例如「办公室 Mac」。设备标识用于两端对照确认是同一台机器，换身份时一眼能看出来，排障时用得上。

## 配对

两台设备连同一个 Wi-Fi，任选一个方向。配对码只经人眼传递，不会出现在网络报文里。

### 本机显示配对码

1. 「设备关联 → 显示配对码」→ 点「生成配对码」。
2. 页面显示 6 位数字、进度条与倒计时，**60 秒内有效**。
3. 在另一台设备上输入这组码完成配对。
4. 过期后显示「已过期，请重新生成」；点「换一个」换一组，点「取消」立刻作废。

### 输入对方显示的配对码

1. 切到「输入配对码」，填入对方显示的 6 位数字（输入框提示为 `例如 482 719`）。
2. 点「配对」，按钮变为「正在查找设备…」，自动在同一 Wi-Fi 下发现对方，**最长等 60 秒**。
3. 成功后页面顶部显示绿色状态条，设备出现在「已配对设备」里。

如果局域网广播被拦（AP 隔离、公司网络），展开 **手动地址** 填对方的 `192.168.1.5` 或 `192.168.1.5:47823` 再配对。

> 另一方向还在进行时，当前标签顶部会提示「本机正在等待配对，配对码还剩 N 秒」，避免误以为点击没生效而反复操作。

配对只建立信任关系，**不会自动开启同步**。

## 开启同步

到 **剪贴板 → 剪贴板同步**，这里是开关式多选，不是下拉选择：

| 开关 | 说明 |
|------|------|
| 局域网直连 | 与配对过的设备点对点传输，不经第三方服务器；副标题会显示「已配对 N 台」 |
| 同步插件 | 安装剪贴板同步插件后经 WebDAV 等通道跨网络同步；开关名称随已选插件变化 |

- **勾选即启用**，两个都勾时按顺序决定优先级，首个优先。
- 想让直连优先，就先勾「局域网直连」再勾插件；直连掉线超过阈值会自动让位给后面的通道，恢复后再切回。切换会写进日志，形如 `通道 p2p → plugin`。
- 只勾直连就只走直连，不会偷偷改走插件。
- 两个都不勾时页面显示「同步已关闭」，剪贴板只留在本机。
- 还没有配对设备时，直连开关的副标题会提示「还没有已配对设备，先到『设备关联』配对」。

## 什么时候会同步

- 直连节点随输入法进程存活：只要曦码·逸在跑，配对过的设备就保持发现与重连。
- 同步开关打开后，输入法在后台自动推送 / 拉取，关闭即时生效，不需要重启输入法。
- 切到别的输入法、或进程被系统回收后连接会断；切回曦码·逸后自动重连。
- 关掉设置程序窗口不影响同步——节点在输入法进程里，不在设置程序里。

## 只同步当前剪贴板

同步只处理「当前这一条」，不会把剪贴板历史整体上传；历史仍留在各自设备本地。手机端通过直连只传纯文本，图片走插件通道。

## 管理已配对设备

- **移除**：在「已配对设备」里点「移除」，会先要一次确认（「确认移除？」），确认后删除信任关系；对方需要重新配对。
- **改名**：改「本机 → 设备名」并保存，下次配对或同步时告知对端；已配对设备上显示的旧名不追溯更新。
- **多台设备**：可以配对多台，但剪贴板是单值资源，同一时刻只保持一条直连。设备较多时建议只保留常用的几台。

## 数据与日志

| 路径 | 内容 |
|------|------|
| `~/Library/Application Support/XimeYi/rime/p2p/` | 本机身份、配对表 `peers.json`、设备名 `device.json` |
| `~/Library/Application Support/XimeYi/ximeyi.log` | 运行日志，搜 `device link` / `p2p:` 可看到节点启动端口、连接与通道切换 |

删除 `p2p/` 目录等于重置身份：所有旧配对都会失效，需要重新配对。

## 排查

| 现象 | 可能原因与处理 |
|------|----------------|
| 配对成功但剪贴板不同步 | 「剪贴板 → 剪贴板同步」里的「局域网直连」开关没勾，配对不等于同步 |
| 生成配对码后对方找不到 | 同一 Wi-Fi、同一网段；关闭 VPN；路由器未开 AP 隔离或访客网络隔离；必要时用手动地址 |
| 输入配对码一直「正在查找设备…」 | 对方页面是否还开着、码是否过期（60 秒）；防火墙或安全软件是否拦截了本地端口 |
| 设置程序关掉后同步停了 | 不会。节点在输入法进程里；真正会断的是切走输入法或输入法进程退出 |
| 切到其它输入法再切回来，第一条没同步 | 连接重建需要几秒，重建后会自动补发最后一条 |
| 移除设备后对方还能看到本机 | 需要在两端都移除；只在一端删，另一端仍保留旧配对记录 |
| 日志里反复出现端口占用 | 输入法进程异常残留，重启输入法或注销后重新登录即可 |

更多问题见[设备互联常见问题](/device-link/faq)。
