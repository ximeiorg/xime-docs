# 手机端（鸿蒙）

鸿蒙版把设备互联做进了设置应用：**配对在主 App 里完成，剪贴板同步由输入法扩展进程常驻的节点负责**。两者通过签名共享的沙箱交换身份与配对表，配对后重新弹出键盘即生效。

> 需要先在系统「设置 → 系统 → 输入法」里把曦码输入法切换为**完整体验模式**。基础访问模式下系统会管控扩展进程（禁网络、禁剪贴板），设备互联不会工作。

## 入口

打开桌面上的「曦码输入法」应用进入设置页，在页面底部的 **智能** 分组里点 **设备互联**（副标题为「局域网内与电脑互传剪贴板（端到端加密）」）。

鸿蒙版只有这一个入口，没有 Android 那样从剪贴板设置二次进入的路径。

## 页面说明

| 区域 | 内容 |
|------|------|
| 剪贴板同步 | 「启用局域网直连同步」开关，同时是设备互联的总开关与通道开关 |
| 本机 | 设备名称、设备标识、存储位置 |
| 配对设备 | 「生成配对码」与「输入配对码」两种配对方式，未开启开关时只显示提示 |
| 说明 | 运行条件、同步时机、加密方式与互斥说明 |

- **设备名称**：配对时显示给对方，留空则用设备型号（如 `HarmonyOS 设备`），可随时修改。
- **设备标识**：由本机密钥派生的短标识，用于两端对照确认是同一台机器；不是账号，也不上传。
- **存储位置**：正常应显示「共享沙箱」。若显示「本机沙箱（不可跨进程）」，说明当前安装包的签名 Profile 没有 `data-group-id`，主 App 写入的配对表输入法读不到，设备互联不会真正生效。

## 首次使用

1. 打开 **设备互联**，先打开「启用局域网直连同步」。开关关闭时配对入口不可用。
2. 按下一节完成一次配对。
3. 回到任意输入框，重新弹出一次键盘，让扩展进程加载新的配对表并连接。

## 配对

两台设备连同一个 Wi-Fi，任选一个方向操作。配对码只经人眼传递，界面上不显示 IP，也不提供二维码。

### 手机显示、电脑输入

1. 手机进入 **设备互联**，在「配对设备」中点击「生成配对码」。
2. 页面显示 6 位数字，**60 秒内有效**。
3. 在电脑上打开 ximed → **设备** → **输入配对码**，填入这 6 位数字并配对；macOS 则在曦码·逸设置程序的 **设备关联 → 输入配对码** 里填。
4. 两端提示成功后，设备出现在手机的「配对设备」列表里。

### 电脑显示、手机输入

1. 电脑上生成配对码（ximed 的「设备 → 显示配对码」，或曦码·逸的「设备关联 → 显示配对码」）。
2. 手机进入 **设备互联**，点击「输入配对码」，填入 6 位数字后点「开始配对」。
3. 等待期间保持两端界面打开，成功后页面显示「配对成功：设备名」。

配对只建立信任关系，**不会自动开始同步**；同一时间只能进行一场配对，进行中再点会提示忙。

## 开启同步

鸿蒙版没有插件通道，所以同步开关就在设备互联页里：

- 打开「启用局域网直连同步」后，本机与已配对设备之间即启用局域网直连。
- 该功能与其他剪贴板同步方式**互斥**，开启时不要再同时使用 WebDAV 等通道，避免同一条剪贴板被两处写入。

## 什么时候会同步

- **打开键盘时**：扩展进程启动同步节点，连接已配对设备，并取回对方当前的剪贴板。
- **使用键盘期间**：本地复制立即推送；收到远端变化后写回系统剪贴板。
- **键盘收起后**：不在后台持续读取剪贴板，下次打开键盘继续。
- **配对完成后**：需要重新弹出一次键盘，已在运行的节点才会去连这台新设备。

## 只同步文本

局域网直连只传纯文本：

- 图片、文件不会通过直连传输，也不会在另一端生成占位内容。
- 不保存剪贴板历史，只同步「当前这一条」。

## 管理已配对设备

- **解除**：在「配对设备」列表中点设备右侧的「解除」，删除信任关系；对方需要重新配对。
- **改名**：修改「本机 → 设备名称」后，后续配对会在对方显示新名称，已配对设备上的旧名称不追溯更新。
- **多台设备**：可以配对多台，但剪贴板是单值资源，同一时刻只保持一条直连。设备较多时建议只保留常用的几台。

## 排查

| 现象 | 可能原因与处理 |
|------|----------------|
| 页面顶部提示「设备互联原生库未编入本安装包」 | 构建时没有先执行 `scripts/build-p2p-ohos.sh`，原生库没有打进包里，需要重新构建 |
| 「存储位置」显示本机沙箱（不可跨进程） | 签名 Profile 缺少 `data-group-id`，配对结果输入法读不到；换成带共享沙箱权限的签名重新安装 |
| 配对入口不可用 | 「启用局域网直连同步」还关着，先打开开关 |
| 生成配对码后对方找不到设备 | 确认同一 Wi-Fi、同一网段；关闭 VPN；确认路由器未开 AP 隔离或访客网络隔离 |
| 输入配对码后一直「正在查找设备…」 | 对方页面是否仍打开、配对码是否已过期；桌面端是否被防火墙拦截 |
| 已配对但不同步 | 输入法是否处于完整体验模式（基础访问模式禁用网络与剪贴板）；是否重新弹过键盘；对端是否在线 |
| 锁屏或长时间不用后失效 | 系统回收了扩展进程，重新打开键盘会自动重连 |
| 换机或重装后连不上 | 本机身份已变化，需要在两端删除旧记录并重新配对 |

更多问题见[设备互联常见问题](/device-link/faq)。
