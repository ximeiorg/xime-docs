# 使用与设置

本文按「候选窗 → 面板 → 托盘 → 语音 → 设置程序」的顺序介绍曦码·澈的日常使用。

## 候选窗

在输入框中打字时，候选窗出现在光标附近：

- 候选按顺序编号，数字键 `1`–`9` 选词，`0` 选第 10 个（候选数量可在外观设置中调整）
- 空格选择第一个候选；回车、退格等按键按 Rime 方案的定义处理
- 候选右侧显示编码提示；不同方案的提示内容不同
- 候选窗右侧有一个**菜单按钮**，点击打开功能面板
- 五笔方案下按住 `Ctrl` 可显示最后一次按键对应的字根，松开隐藏

> 候选窗跟随光标定位，具体位置由 KWin 的输入法协议决定；多屏或缩放场景下如位置异常，请先确认使用的是 Wayland 会话。

## 中英文与标点

| 操作 | 效果 |
|------|------|
| `Shift` | 切换中文 / 英文输入 |
| `Ctrl+Space` | 启停输入法（停用后按键直接交给应用，托盘显示 EN 占位） |
| `[` / `]` | 候选上一页 / 下一页（方案也支持 `-` / `=` 与 `Tab`） |
| `Ctrl+Alt+V` | 开始 / 停止语音输入 |

快捷键的实际绑定以「设置 → 快捷键」页与当前 Rime 方案为准。`Ctrl+Space` 是启停输入法，不是简单的中英切换：停用期间不会组字，适合临时让所有按键直通应用。

## 菜单面板

点击候选窗右侧的菜单按钮，打开面板：

| 入口 | 作用 |
|------|------|
| 剪切板 | 查看最近复制/同步的内容，点击条目直接上屏 |
| 快捷发送 | 常用短语列表，点击上屏；支持编码触发 |
| 表情 | 表情符号网格，点击上屏（需要表情插件） |
| 符号 | 常用符号网格，点击上屏 |
| 语音输入 | 开始/停止语音听写 |
| 设置 | 打开设置程序 |

面板内用底部翻页按钮翻页；`Esc` 关闭面板。中文状态、没有正在组字时，输入 `;` 可以直接打开表情页（需要已安装表情插件）。

## 剪贴板与快捷发送

- **剪贴板**：自动记录复制过的文本，在面板中点击即可插入。记录只保存在本机 `clipboard.db`。
- **快捷发送**：在「设置 → 剪贴板 → 快捷发送」中维护；可以给短语设置编码，输入编码前缀时会进入候选栏。
- **同步**：在「设置 → 剪贴板 → 剪贴板同步」中选择局域网直连或同步插件；详见下文。

剪贴板历史有数量上限，超出后自动清理较旧记录。清空历史不会影响快捷发送。

## 托盘

输入法激活时，系统托盘出现 **ZH / EN** 图标：

- **左键单击**：切换中文 / 英文
- **右键菜单**：
  - 切换中英文
  - 当前已启用方案列表（点击切换，当前方案打 ✓）
  - 语音输入
  - 设置...
  - 重新部署
  - 退出

「重新部署」会重新加载 Rime 配置并重建方案产物；修改方案、词典或 `*.custom.yaml` 后使用。

## 语音输入

曦码·澈支持**本地离线语音识别**：

1. 在「设置 → 语音转文本」中下载一个语音模型（只需下载一次）。
2. 把光标放进输入框，按 `Ctrl+Alt+V`，或点托盘菜单的「语音输入」。
3. 说话时候选栏或悬浮层显示识别进度，停顿后文本自动上屏。
4. 按 `Esc` 或再次触发快捷键结束听写。

语音识别在本机运行，录音不上传。输入法未激活时无法上屏，此时请先点击目标输入框再开始。

## 设置程序

通过托盘「设置...」、命令 `xime-setup` 或应用菜单打开「曦码·澈输入法设置」。

| 页面 | 作用 |
|------|------|
| 输入方案 | 查看已安装/已下载方案，部署、导入方案包、打开数据目录、还原内置方案包 |
| 词典 | 用户词典与快捷短语的新增、编辑、删除、搜索、备份/恢复、导入/导出 |
| 外观 | 浅色/深色/跟随系统、配色方案、字号、候选数量、圆角，保存与撤销 |
| 快捷键 | 查看中英切换、标点、翻页、字根等快捷键 |
| 扩展商店 | 浏览并安装方案、模型、插件 |
| 插件管理 | 启用/停用、卸载已安装插件 |
| 语音转文本 | 下载/切换语音模型，试听识别效果 |
| 设备关联 | 局域网配对（设备互传），开发中 |
| 剪贴板 | 剪贴板历史、快捷发送、剪贴板同步 |
| 同步与备份 | WebDAV 备份与恢复 |
| 关于 | 版本、运行平台、配置目录、许可证与项目主页 |

### 输入方案

- **部署方案**：修改方案或配置后必须部署，等待几秒生效。
- **导入方案**：支持 `.zip` / `.tar.gz`，可拖入窗口、选择本地文件或填写远程 URL。
- **打开数据目录**：直接打开 `~/.config/xime/rime/`。
- **还原内置方案包**：把方案恢复为随包自带的版本；会先提示冲突，确认后执行。

曦码·澈只使用项目自带的 `rime-wubi` 方案集，不会混入系统 librime-data 的内置方案。

### 词典

- **用户词典**：按方案查看词条，支持搜索、新增、编辑、删除；整本支持备份快照、恢复、导出/导入文本。
- **快捷短语**：维护常用短语与触发编码；在输入法中输入编码前缀即可进入候选栏。

### 外观

- 外观模式：浅色 / 深色 / 跟随系统
- 浅色、深色配色方案
- 候选字号、候选数量（1–10）、候选窗圆角
- 保存外观设置；支持撤销上一次修改、恢复用户提供的配置

### 剪贴板

页面分三个标签：

1. **剪贴板历史**：查看、刷新、清空；点击条目后可「添加到快捷发送」或删除。
2. **快捷发送**：新增、编辑、删除短语，设置编码。
3. **剪贴板同步**：
   - **局域网直连（设备互传）**：需要先在「设备关联」配对；开发中，见下文。
   - **同步插件**：安装剪贴板同步插件后勾选，可经 WebDAV 等跨网络同步。

同步只同步「当前剪贴板」，不会把历史整体上传。

### 同步与备份

「同步与备份」用于把配置、方案、词典等打包备份到 WebDAV，或从备份恢复。它与「剪贴板同步」是两件事：前者是时点备份，后者是持续同步。

### 设备互传（开发中）

「设备关联」页提供局域网配对：一台显示 6 位配对码，另一台输入，60 秒内有效。配对成功后在「剪贴板 → 剪贴板同步」中打开「局域网直连」。

**当前限制**：

- 该功能仍在开发中，尚未完成双机实测，行为可能随版本变化。
- 接收到的远端文本会进入 `clipboard.db`，可在候选栏「剪切板」面板中点击上屏；**尚未自动写入系统剪贴板**，因此不能直接 `Ctrl+V`。
- 如果没有已配对设备，直连不会同步任何内容。
- 如遇不同步，请先改用「同步插件」通道，并关注后续版本说明。

协议与配对设计可参考[设备互联](/device-link/)文档；曦码·澈目前尚未纳入该文档的正式桌面端步骤。

## 数据与配置

所有 Rime 数据在单目录 `~/.config/xime/rime/`：

```
~/.config/xime/
├── rime/                 # 方案、词典、用户配置、build/ 产物
├── xime.custom.yaml      # 外观与行为自定义
├── clipboard.db          # 剪贴板历史与快捷发送
├── plugins/              # 插件
├── models/               # 语音模型
├── p2p/                  # 设备关联身份与配对表（开发中）
├── clipboard_sync.toml   # 剪贴板同步配置
└── xime.log.YYYY-MM-DD   # 日志
```

- 修改 `rime/` 下的方案或 `*.custom.yaml` 后，点托盘「重新部署」。
- 备份可以直接复制 `~/.config/xime/`，也可以使用「同步与备份」页。
- 排障日志在 `~/.config/xime/xime.log.*`；需要更详细日志时，可调整 `xime.yaml` 里的 `log_level`。

## 卸载与重置

- 卸载软件包后，用户配置仍保留在 `~/.config/xime`；需要彻底清理时手动删除。
- 开发安装可运行仓库的 `uninstall.sh`；加 `--purge` 会同时删除配置。
- 卸载后如 KWin 仍指向 Xime，请清空 `kwinrc` 的 `[Wayland] VirtualKeyboard` 并重新登录。
