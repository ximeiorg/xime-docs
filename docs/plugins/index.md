# Xime 插件列表

这里展示所有可用的 Xime 插件。插件为独立 APK（`.xipk`），需要单独安装。

## 官方插件

### FunAsr（阿里百炼在线语音识别）

**版本：** 1.0.0

**说明：** 阿里百炼 FunAsr 在线语音识别（WebSocket 流式，自带标点）。安装后在「设置 → 语音转文本」中配置 API Key 并选择使用。

**下载：** [APK](https://github.com/ximeiorg/Xime/releases) | **源码：** [GitHub](https://github.com/ximeiorg/Xime/tree/main/plugins/funasr-asr)

---

### Kaomoji（颜文字）

**版本：** 2.0.0-beta1

**说明：** 预定义颜文字数据，包含丰富的日式颜文字表情如 `(^_^)`、`(T_T)`、`(≧▽≦)`、`(╯°□°)╯︵ ┻━┻`

![表情键盘插件](/Screenshot/plugin_light.jpg)

**下载：** [APK](https://github.com/ximeiorg/Xime/releases) | **源码：** [GitHub](https://github.com/ximeiorg/Xime/tree/main/plugins/kaomoji)

---

### Meme Bunny（恶搞兔）

**版本：** 2.0.0-beta1

**说明：** 恶搞兔表情包，从 APK assets 加载表情图片

**下载：** [APK](https://github.com/ximeiorg/Xime/releases) | **源码：** [GitHub](https://github.com/ximeiorg/Xime/tree/main/plugins/meme-bunny)

---

## 安装插件

1. 下载插件 APK
2. 安装到设备
3. 在Xime 设置中启用插件

## 开发自己的插件

如果你想开发自己的表情插件，请查看 [插件开发指南](./PLUGIN_DEVELOPMENT_GUIDE)。
