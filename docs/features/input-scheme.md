# 输入方案

::: info 适用平台
**Android · Windows · Linux**。功能本身三端通用，入口与界面不同；本文以 Android 界面为例，Windows / Linux 的操作路径见对应平台文档。
:::

> Windows 桌面版（曦码·曜）的方案管理界面与本文不同，见 [Windows 输入方案](/pc/input-scheme)。


输入方案管理允许用户添加、切换和管理不同的输入方案（如五笔86、五笔98、拼音、拼音九键、手写等）。

## 内置方案

应用内置以下输入方案（由 `rime-wubi` 子模块提供，随 APK 打包，无需下载）：

| 方案 | schema_id | 说明 |
|------|-----------|------|
| 五笔86 | `wubi86` | 纯五笔输入 |
| 五笔98 | `wubi98` | 五笔98 输入 |
| 五笔拼音 | `wubi86_pinyin` | 五笔+拼音混合输入 |
| 简入繁出 | `wubi86_trad` | 五笔输入、繁体输出 |
| 拼音混输繁体 | `wubi86_trad_pinyin` | 五笔+拼音混输、繁体输出 |
| 简体拼音 | `pinyin_simp` | 简体拼音输入 |
| 拼音九键 | `t9_pinyin` | 九宫格拼音输入 |
| 手写输入 | `handwriting` | 手写识别输入（需下载手写模型） |
| 大写数字 | `numbers` | 数字输入 |

其他方案（如雾凇拼音、仓颉等）需用户自行导入。请参考下方[导入方案](#导入方案)章节。

## 模糊音

Xime 默认内置的是**五笔方案集**，其中包含的拼音能力（五笔拼音混输、忘码时的拼音反查、简体拼音、拼音九键）主要是**为五笔用户提供的辅助**——方便忘码、打生僻字时用拼音查字，并不是面向纯拼音用户的完整拼音方案。

关于模糊音，需要注意：

- 内置拼音只有少量拼写容错规则（如 `un`/`uen`、`ui`/`uei`、简拼等），**没有提供模糊音**（n/l、zh/z、ch/c、sh/s、an/ang、en/eng、in/ing 等常见模糊音均不支持）
- Xime 本身也不提供全局的模糊音开关——在 Rime 生态中，模糊音由**输入方案自身**的拼写运算规则决定，属于方案级配置，每个方案的支持情况不同

如果你需要带模糊音的拼音输入：

1. 在「扩展商店 → 方案」中选择一个专门的拼音方案（如雾凇拼音等）下载安装；
2. **查看该方案自己的文档**，确认它是否支持模糊音、以及模糊音的设置方法（不同方案差别较大）。

安装并启用后，点击「部署方案」生效，步骤见[导入方案](#导入方案)。

## 方案列表

在「设置」→「方案与词库」→「输入方案」中，可以看到所有可用的输入方案：

- **已导入** — 顶部独立入口卡片，进入后可管理已下载 / 导入的方案包（详见 [导入方案](#导入方案)）
- **已启用** — 当前已开启的方案，显示为已启用列表
- **未启用** — 存在于 `rime/` 目录中但尚未启用的方案，列在已启用列表下方

每个方案使用右侧的 Switch 开关来启用或停用；点击卡片可将已启用且已编译的方案设为当前方案。

> 提示：修改启用状态后，点击底部的「部署方案」按钮使更改生效。

## 导入方案

支持多种方式导入新的输入方案，兼容常见的 Rime 配置包（如雾凇拼音 rime-ice 等）。

导入入口位于**已导入页面**：在「设置」→「方案与词库」→「输入方案」中点击顶部「已导入」卡片进入，再点击右上角「+」选择导入方式。首次使用时会弹出「导入方案须知」提醒，确认（可勾选「不再显示」）后继续。

### 从文件选择

1. 点击右上角「+」→「从文件选择」
2. 选择 `.zip` 压缩包（包含 `.schema.yaml` 和 `.dict.yaml`）
3. 系统会自动解压并提取方案文件到 `rime/`
4. 导入的包会显示在列表中，点击「安装」

### 无线导入（浏览器导入）

1. 点击右上角「+」→「浏览器导入」
2. 在弹出的页面中查看二维码和上传地址（如 `http://192.168.1.100:5000`）
3. 在同一 Wi-Fi 下的电脑浏览器中打开该地址
4. 拖拽或选择 `.zip` 或 `.tar.gz` 压缩包上传
5. 上传完成后手机端会自动更新方案列表
6. 页面在手机窄屏上也可直接打开（自动改为上下堆叠布局）
7. 页面左侧「数据目录」可直接编辑 `rime/` 下的文本配置（`yaml` / `yml` / `txt` / `md` / `json` / `conf` / `lua`），保存后回手机点一次「部署方案」生效

> 在线编辑只允许 `rime/` 目录下的文本文件（单个文件 ≤ 2MB）；`build/`、`trash/`、`*.userdb` 和二进制文件不提供编辑入口。

### 网络导入

1. 点击右上角「+」→「网络导入」
2. 在弹出的对话框中输入压缩包的下载 URL
3. 支持 `.zip` 和 `.tar.gz` 两种格式
4. 点击确定后自动下载、解压并更新方案目录

### 管理已导入的方案包

已导入页面会列出所有方案包，并标注状态：

- **已安装 / 已下载** — 方案包当前的状态
- **安装** — 把「已下载」的方案包安装到 `rime/`（安装完成后会自动触发部署，界面区分「安装中 / 部署中」状态，v3.3.0+）
- **卸载** — 移除「已安装」的方案包（会同步清理该包的相关信息，v3.4.3+）
- **删除下载文件** — 删除已下载的文件（`builtin` 包不可删除）

> **冲突提示**（v3.0.0+）：导入的文件与已安装方案中同名但内容不同时，会明确提示并列出冲突明细，不会静默覆盖已安装方案的内容；安装时可选择「确认卸载并安装」。

> **开箱方案集**（v3.4.2+）：安装方案包时，应用会读取包内 `default.yaml` 声明的开箱启用方案集自动启用；未声明方案集的包不会自动启用任何方案，会提示你在「已启用」列表中手动选择，避免误用依赖缺失的方案。

> 导入完成后需在「已启用」列表启用方案，再点「部署方案」生效。

### 兼容性说明

- 支持包含子目录结构的压缩包，例如雾凇拼音（rime-ice）等方案包中常见的 `cn_dicts/`、`en_dicts/`、`opencc/` 等目录会被正确解压
- 系统会自动检测压缩包中 `.schema.yaml` 文件所在的目录层级，并将其作为根目录解压到 `rime/` 下
- 因此无论是直接打包的方案文件，还是从 GitHub 下载的带有外层目录（如 `rime-ice-main/`）的压缩包，都可以直接导入

## 切换方案

在键盘上：

1. 点击键盘上的 Logo 按钮打开功能菜单
2. 菜单中显示已启用且已部署的方案名称
3. 点击即可切换到对应方案

在设置中：

1. 进入「输入方案」设置页面
2. 在「已启用」列表中使用 Switch 开启或关闭方案
3. 点击底部「部署方案」按钮使更改生效

## 部署方案

每次添加、启用或删除方案后，都需要执行部署操作才能生效：

1. 在「输入方案」页面底部点击「部署方案」
2. 等待部署完成
3. 部署完成后新的方案即可使用

> **部署机制（v3.4.x+）**：新增方案时优先增量部署（仅编译缺失编译产物的方案），部署完成后会自动校验已启用方案是否都有编译产物，缺失时给出明确提示，不再出现部署「成功」但方案不可用的情况。安装与部署会保留你的自定义资源（`xime.custom.yaml`、主题、字体、自定义短语等），不会被包内文件覆盖。

> ⚠️ **按需启用方案**：部署时会编译所有已启用的方案所引用的词典。如果一次性启用了过多方案（尤其是包含大词库的方案，如雾凇拼音的 `tencent.dict.yaml` 等），部署时间会显著增长。建议只开启你实际会用到的方案，不需要的方案保持关闭状态。

## 删除方案

1. 进入「输入方案」→「已导入」页面
2. 找到要删除的方案包，点击「卸载」（已安装时）或「删除下载文件」图标（已下载时）
3. 若方案已启用，建议先在「已启用」列表中关闭再卸载
4. 卸载 / 删除后点击「部署方案」使更改生效

卸载时会同步清理该包的相关信息（v3.4.3+），列表中不会残留「未知」条目。

## 注意事项

- 添加方案后，需要手动在「已启用」列表中开启，然后部署才能生效
- 导入的压缩包应包含 `.schema.yaml` 和对应的 `.dict.yaml` 文件
- 部署时间取决于启用的方案数量和词典大小，请耐心等待
- 切换方案后必须执行部署才能生效
- 雾凇拼音等大词库方案请按需启用，不要一次性全部开启，否则首次部署可能需要数分钟
- **`default.custom.yaml` 属于用户**（v3.4.1+）：应用不再写入该文件，启用方案列表保存在应用内部（存量配置自动迁移）。手写的 `default.custom.yaml` 补丁（如 `key_binder`）部署时会保留；方案包自带的 `schema_list` 块会被剥离，不会覆盖应用的启用列表
