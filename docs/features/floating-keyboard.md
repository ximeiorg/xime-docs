# 悬浮键盘

悬浮键盘（v2.5.0+）让键盘以**悬浮卡片**的形式显示在屏幕中，不占据底部停靠区域，应用内容完整可见，可以边浏览边打字。

## 开关与形态

- **切换入口**：功能菜单或工具栏的 **「悬浮模式」** 按钮，一键切换
- 卡片宽度为竖屏屏幕宽度的 **85%**，按键与字号按比例缩小；横屏下卡片同样保持竖屏形态（居中悬浮）
- 悬浮模式下菜单里的「键盘调节」入口隐藏；工具面板类功能暂不支持悬浮模式

## 拖动与位置记忆

- 按住卡片顶部的**拖动条（握条）**即可拖动到屏幕任意位置
- 位置**自动记忆**：横屏与竖屏的位置分开保存，重启键盘或设备后保持
- 边界钳制：卡片不会顶出屏幕顶部，也不会压进导航栏/手势条区域

## 拖到底部快速退出

悬浮键盘**拖到屏幕底部**时有一组快捷交互（v3.0.0+）：

1. 拖到最低点时**震动一次**，同时屏幕底部泛出**主题色的呼吸光效**——提示可以退出了
2. 保持按住可继续来回拖：拖离底部光效消失，再拖回来重新出现
3. **在底部松手**，悬浮键盘立即切换回普通（停靠全屏）键盘
4. 不在底部松手则照常保存位置

## 候选与展开页

- 悬浮卡片内使用与普通键盘一致的候选栏与按键布局
- 点击「更多」展开候选页时，展开页按**卡片宽度**自适应排版（非全屏宽），横屏下同样正常

## 常见问题

**Q：悬浮模式下拖动键盘，卡片周围的应用点不动？**
卡片四周的触摸区域与卡片边缘严格对齐，区域外的点击都会透传给应用；如遇到异常请升级到最新版本。

**Q：为什么悬浮键盘比普通键盘小？**
悬浮卡片按 85% 比例缩放（宽度、按键高度与字号同步缩小），以减少遮挡；需要大键盘时退出悬浮模式即可（拖到底部松手最快）。
