# 剪贴板管理

剪贴板功能自动保存复制的内容，方便用户快速调用历史记录。

## 功能特性

- **自动保存** - 复制的文本会自动保存到剪贴板历史（v2.6.0 起基于 Room 数据库本地存储）
- **图片剪贴板**（v3.0.0+） - 复制的图片自动捕获保存，候选栏与剪贴板统一展示、点击插入
- **分类查看** - 通过“剪贴板”和“快捷发送”两个标签管理
- **文本拆分（分词）** - 将剪贴板文本拆分为单个字符，逐字选择输入
- **快捷发送** - 收藏常用内容到快捷发送，永久保存
- **滑动操作** - 在项目上滑动显示拆词、快捷发送、删除等操作选项
- **批量管理** - 支持删除单条记录或清空全部历史
- **多设备同步**（v2.6.0+） - 通过剪贴板同步插件在多台设备间同步剪贴板内容（文本与图片）

## 使用方法

1. 点击键盘上的 Logo 按钮打开功能菜单
2. 选择“剪贴板”进入剪贴板界面
3. 在“剪贴板”标签查看所有复制历史，在“快捷发送”标签查看收藏内容
4. 点击条目可直接插入到输入框
5. **滑动操作**：在条目上左右滑动，可显示操作面板（拆词、快捷发送、删除）
6. 点击星形图标可将内容添加到快捷发送
7. 点击删除图标可移除单条记录

## 文本拆分（分词）

文本拆分功能可将剪贴板中的一段文本按字符拆分为单个字，方便逐字选择输入：

1. 在剪贴板列表中，在需要拆分的条目上滑动
2. 点击“拆词”按钮
3. 进入分词视图，每个字符独立显示
4. 点击单个字符即可输入，点击删除可移除
5. 点击“发送”将选中的字符一次性提交

## 图片剪贴板（v3.0.0+）

复制图片时会自动捕获并保存到本地剪贴板历史：

- **内容寻址存储** - 图片以 SHA-256 哈希命名，相同内容的图片自动去重
- **配额管理** - 图片数量、单张大小与总容量均有限制，可在设置中调整
- **隐私保护** - 敏感剪贴板内容（如密码管理器复制的条目）不会被保存
- 候选栏中图片与文本条目统一处理，点击即插入

## 剪贴板同步

v2.6.0 起支持通过**剪贴板同步插件**在多台设备间同步剪贴板内容（文本与图片），例如通过 WebDAV 网盘（如坚果云）或 S3 兼容对象存储中转：

1. 在「扩展商店 → 插件」中下载并启用剪贴板同步插件（如「WebDAV 剪贴板同步」「S3 剪贴板同步」）
2. 在插件的配置表单中填写同步服务信息（如 WebDAV 地址、账号与密码）
3. 在「设置 → 剪贴板同步」中管理同步配置，支持动态启停

### 工作机制

- **插件化同步** - 同步通道由插件提供，支持安装多个同步插件并选择首选插件
- **拉取间隔可调**（v3.0.0+） - 插件可通过配置项 `pull_interval_seconds` 调整自动拉取间隔（1~600 秒，默认 30 秒），修改后即时生效；也可在设置中手动拉取
- **加密传输** - 支持加密 API 与加密传输，剪贴板内容不以明文形式暴露
- **网络授权** - 同步插件需联网，首次使用时请在插件管理中为插件声明的域名授权

## 注意事项

- 剪贴板历史仅保存在本地（Room 数据库与图片文件），除非启用同步插件
- Android 10 及以上系统限制后台读取剪贴板，仅在使用键盘时自动保存复制内容
