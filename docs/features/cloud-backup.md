# 云备份

云备份（v2.8.0+）通过**备份插件**将 Xime 的全部个人数据打包备份到云端，并支持一键恢复。备份传输完全插件化：宿主负责打包与落盘，插件只负责把备份包上传/下载到具体的服务（如 WebDAV），后续可扩展更多服务商插件。

> [!NOTE]
> 内置的 WebDAV 同步功能已在 v2.8.0 移除，由本功能（WebDAV 备份插件）替代。旧版同步的散文件不是备份包格式，无法在本功能中看到或恢复。

## 备份内容

| 内容 | 说明 | 备份模式 |
|------|------|----------|
| Rime 配置与词库 | `rime/` 下的方案、词典、用户配置（自动排除 `build/` 编译产物） | 仅配置 / 完整 |
| T9 自造词 | Rime 用户词典（userdb），九键输入的记忆词 | 仅配置 / 完整 |
| 应用设置 | 按键效果、主题、键盘高度等偏好设置 | 仅配置 / 完整 |
| 插件配置 | 各已安装插件的配置（密文存储，原样备份） | 仅配置 / 完整 |
| 插件启用状态 | 已安装插件列表与启用开关 | 仅配置 / 完整 |
| 插件包 | 插件安装包本体 | 仅完整备份 |

::: warning 建议在非输入状态备份/恢复
自造词数据库（userdb）在输入法运行中以 leveldb 存储，运行中打包快照存在一致性风险。建议在空闲状态（未在打字）执行备份与恢复。
:::

## 使用步骤

### 1. 安装备份插件

进入「设置 → 扩展商店 → 插件」，安装 **WebDAV 备份** 插件（或任何实现了备份能力的插件）。

### 2. 配置插件

进入「设置 → 同步与备份 → 云备份」，选择备份插件后填写配置：

**坚果云示例：**

1. 打开坚果云 App →「设置」→「第三方应用管理」→「添加应用密码」
2. 在插件配置中填写：

| 字段 | 坚果云示例 | 说明 |
|------|-----------|------|
| 服务器地址 | `https://dav.jianguoyun.com/dav` | WebDAV 服务器地址 |
| 用户名 | 坚果云账号邮箱 | |
| 密码 | 第 1 步生成的**应用密码** | 不是登录密码 |
| 远程目录 | `xime_backup` | 备份包存放目录，不存在会自动创建 |

3. 点击「测试连接」验证配置（首次连接会请求网络授权）

### 3. 备份与恢复

- **立即备份** - 打包当前数据并上传，备份包以时间戳命名
- **查看远端** - 列出云端已有的备份包
- **恢复** - 下载选中备份包并覆盖本地对应数据，恢复完成后建议重新部署方案
- **删除** - 删除云端备份包

## 常见问题

**Q：恢复后候选词/自造词没有完全回滚？**
恢复采用覆盖合并方式，不会删除备份之后新增的词条；如需精确回滚到备份时点，恢复后手动删除多余的自造词即可。

**Q：备份包很大吗？**
备份包为 zip 格式，仅含文本配置与词库数据，通常在数 MB 以内；完整备份含插件包时会更大。
