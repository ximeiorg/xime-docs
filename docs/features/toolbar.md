# 工具栏自定义

::: info 适用平台
**仅 Android**。这是触屏键盘或 Android 端专属功能，Windows / Linux 桌面版没有对应入口。
:::


工具栏位于候选栏右侧，显示常用功能的快捷按钮。Xime 支持自定义工具栏按钮布局，让用户将最常用的功能放在触手可及的位置。

## 功能特性

- **自定义按钮** - 点按圆形图标切换按钮的显示 / 隐藏
- **实时预览** - 定制界面顶部实时预览当前已选按钮
- **分页显示** - 按钮多于 8 个时分页，底部圆点指示，左右滑动翻页
- **按压反馈** - 按钮按压状态背景色和透明度反馈
- **主题适配** - 自动适配深色/浅色主题

## 可选的工具栏按钮

| 按钮 | 功能 |
|------|------|
| 表情 | 打开表情面板 |
| 剪贴板 | 打开剪贴板历史记录 |
| 方案选择 | 切换输入方案 |
| 快捷发送 | 打开快捷发送内容 |
| 符号 | 打开符号面板 |
| 悬浮 | 切换悬浮键盘模式 |
| 全选 | 全选输入框内容 |
| 复制 | 复制选中内容 |
| 粘贴 | 粘贴剪贴板内容 |
| 段首 | 光标移到段首 |
| 段尾 | 光标移到段尾 |
| 手写找字 | 手写查询对应编码（需已安装手写模型） |
| 编辑 | 打开编辑面板 |
| 语音 | 语音输入（需已启用语音转文本） |

> 「手写找字」「语音」按可用性显示：未安装手写模型 / 未启用语音转文本时，定制列表里不会出现这两个按钮。

部分插件也可向工具栏注册按钮（如打开插件面板），随插件安装出现。

## 自定义方法

1. 点击键盘上的 Logo 按钮打开功能菜单
2. 点击「定制工具栏」
3. 在定制界面中，点按圆形图标即可切换按钮的显示 / 隐藏（右上角实时预览已选按钮）
4. 按钮多于 8 个时左右滑动翻页
5. 点击左上角「确定」保存并退出

## 分页显示

当按钮较多时，定制界面会自动分页：

- **竖屏模式** - 每页最多显示 8 个按钮，底部显示圆点分页指示器
- **横屏模式** - 使用单行多列布局，充分利用横向空间
- **滑动翻页** - 在按钮区域左右滑动可切换页面
