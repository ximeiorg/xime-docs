# 词库管理

> [!TIP]
> **v3.0.0 起词库管理全面重构**：页面改为「用户词库 / 快捷短语」两个入口下钻；**用户词库支持查看、增删、导出与导入**（与 PC 端小狼毫/鼠须管同格式）；原「个人词库」页签移除，方案内置词表移至「输入方案 → ⋮ → 方案词表」。

Xime 的词库数据分两类：**用户词库**（打字自动积累）与**快捷短语**（手动维护的全局短语），适用于不同场景。

---

## 快速判断：该用哪个？

| 你的需求 | 用哪个？ |
|---|---|
| 查看/删除打字时自动积累的词，或补录词条 | ✅ **用户词库** |
| 把词库导出备份，或从 PC 端（小狼毫/鼠须管）搬词进来 | ✅ **用户词库 · 导出/导入文本码表** |
| 添加一个**简写/缩写**（如 `dd` → 等等、`yxdz` → 邮箱） | ✅ **快捷短语** |
| 邮箱、网址、地址等固定短语，所有方案通用 | ✅ **快捷短语** |
| 浏览方案自带的静态码表 | 「输入方案 → ⋮ → 方案词表」 |

---

## 用户词库

用户词库是**打字时自动积累**的个人词典：每次选中的词（含调频计数）都会记录下来，按词典分别存储（与 PC 端 Rime 的 userdb 完全同格式）。

### 查看与搜索

入口：**设置 → 方案与词库 → 词库管理 → 用户词库**。

- 顶部卡片切换词典（默认选中当前方案引用的词典），列出本机全部用户词库
- 条目显示**词、编码、频率**；顶部搜索框按词或编码过滤
- 词典显示最近更新时间；导入/删除等操作后自动刷新

### 添加词条

点击右下角 **添加** 按钮，填写**词、编码、频率**（频率留空默认为 1）。

- 编码应符合当前方案的编码规则（拼音用全拼、五笔用字根码）
- 同词同码再次添加时取**较大频率**（调不低：需要降低权重先删除再重新添加）

### 删除词条

点击条目上的删除图标，确认后即从用户词典移除：

- 删除采用**标记删除**：如果方案自带词表里也有这个词，它仍会出现
- 之后再选中该词会被**重新记录**（相当于"复活"），适合清理打错的词

### 导出 / 导入文本码表

词库页右上角 **⋮ 菜单**提供两个操作，格式与 PC 端小狼毫/鼠须管互通：

- **导出**：生成文本码表（`词<TAB>编码<TAB>频率`，含 `#@` 元数据头与注释行），可存到任意位置
- **导入**：从文本码表合并导入；**同词同码取较大频率**，已删除词条也可通过负频率标记删除
- 导入前会校验文件（二进制/空内容直接报错，不会改动词库）

> [!WARNING]
> 添加或导入的编码**必须符合方案编码规则**。在拼音词库写入 `s j` 这类无效编码，会把所有以 `s` 开头的词全部检出，造成候选爆炸、输入卡顿。

---

## 长按删除自造词（v2.8.0+）

在候选栏**长按**某个候选词，弹窗确认后可将其从用户词典中移除，适合快速清理打错的"自造词"：

- 长按候选 → 确认删除 → 该词不再出现（用户词典标记删除）
- 九键与全键盘均可用
- 仅对当前候选列表中的词条生效；完整管理请使用「用户词库」页面

## 快捷短语

快捷短语是**全局共享**的短语，所有输入方案都可使用。存储在 `custom_phrase.txt` 文件中。

入口：**设置 → 方案与词库 → 词库管理 → 快捷短语**。支持添加（表单：内容/编码/权重）、编辑与删除。

### 原理

快捷短语使用独立的 `table_translator`（`db_class: stabledb`）加载，运行期读取文本文件，**不经过编译**、**不依赖主词典音节表**。因此：

- **任意编码都可用**，不受方案编码规则限制
- 添加后部署即可生效，无需等待编译
- **不会参与造词**，是固定的文本映射

### 适合简拼、缩写、特殊编码

| 场景 | 编码 | 输出 |
|---|---|---|
| 常用口语 | `dd` | 等等 |
| 常用口语 | `bzd` | 不知道 |
| 邮箱 | `yxdz` | kingzcheung@gmail.com |
| 网址 | `github` | https://github.com |

```
等等	dd	99
不知道	bzd	98
kingzcheung@gmail.com	yxdz	99
https://github.com	github	88
```

### 权重

快捷短语支持权重字段（第 3 列），权重越高排序越靠前。建议将常用短语权重设高（如 `99`），低频短语设低（如 `1`）。

### 注意事项

> [!IMPORTANT]
> 快捷短语中的词条**不会参与造词**。例如你把 `的` 设为 `d`，那么 `的` 将无法与其他词组合成新词。因此：
> - ✅ 适合固定短语（邮箱、地址、常用语缩写）
> - ❌ 不宜将单字全拼（`a`、`o`、`e`、`de`）放入快捷短语，否则这些字无法参与造词

## 方案词表

方案自带的静态码表（如五笔拼音 9 万余条）在「**输入方案 → ⋮ → 方案词表**」中只读浏览：

- 支持按方案切换与搜索，显示词条总数
- v3.0.0 起从词库管理页移入（原「方案词库」页签）

## 对比一览

| | 用户词库 | 快捷短语 |
|---|---|---|
| **数据来源** | 打字自动积累 + 手动添加/导入 | 手动维护 |
| **作用域** | 按词典存储，默认跟随当前方案 | 全局共享 |
| **编码规则** | 建议符合方案编码规则 | 任意编码（简拼、缩写均可） |
| **实现机制** | leveldb（userdb） | stabledb 运行期读取 `custom_phrase.txt` |
| **参与造词** | ✅ 是（含调频） | ❌ 否 |
| **权重支持** | 支持（取较大值合并） | 支持 |
| **管理能力** | 查看/搜索/增删/导出/导入（v3.0.0+） | 增删改查 |
| **适用场景** | 自动积累的词与完整编码词 | 缩写、邮箱、网址等固定短语 |

## 操作入口

设置 → 方案与词库：

- **词库管理 → 用户词库** - 查看、搜索、添加、删除，导出/导入文本码表
- **词库管理 → 快捷短语** - 管理全局快捷短语（增删改查与权重）
- **输入方案 → ⋮ → 方案词表** - 只读浏览方案内置词典

修改快捷短语后需**部署方案**生效；用户词库的增删即时生效。
