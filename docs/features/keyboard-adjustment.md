# 键盘调节

键盘调节（v3.0.0 起全面重构）提供微信输入法式的可视化调整：调节时键盘完整可见、蒙深色半透明遮罩，**上下左右四条边都能拖**，拖动实时预览，确定后才保存。

## 进入键盘调节

1. 在键盘显示状态下，点击候选栏左侧的 **Xime Logo 图标**
2. 在弹出的菜单中选择 **「键盘调节」**
3. 键盘整体蒙上深色半透明遮罩（按键隐约可见），进入调节模式

> [!NOTE]
> 悬浮键盘模式下菜单不提供「键盘调节」入口（先退出悬浮再调节）；硬件键盘（紧凑模式）下无此入口。

## 四边手柄

| 手柄 | 操作 | 效果 |
|------|------|------|
| 顶部 **≡** | 上下拖动 | 调整键盘**高度**：底边锚定屏幕底部，顶边跟手 |
| 底部 **≡** | 上下拖动 | 同样调整**高度**：底边跟手（下拖变高、上拖变矮），**顶边保持不动** |
| 左侧 **‖** | 左右拖动 | 调整**左边距**：键盘左缘内收/展开 |
| 右侧 **‖** | 左右拖动 | 调整**右边距**：与左侧独立，两侧不等宽时键盘整体偏移（可借此左右挪动键盘） |

遮罩中部有三个按钮，在遮罩内水平均分：

- **重置** - 恢复默认高度与边距（进入预览态，还需点「确定」才生效）
- **取消** - 放弃本次全部调整，恢复进入前的状态
- **确定** - 保存调整结果，立即生效并持久化

## 调整范围

- **高度**：竖屏为屏幕高度的 25%~60%，横屏为 30%~70%
- **边距**：每侧最多收窄屏幕宽度的 25%，键盘最窄约 240dp
- 拖动手感：拖动过程中键盘实时跟手预览，松手不保存（以「确定」为准）

## 横竖屏独立

横屏和竖屏的高度**分开存储**，旋转设备时自动加载对应方向的设置；宽度边距两个方向共用。

## 与旧版的差异（v2.x → v3.0.0）

- v2.x 的「拖顶部横条调高度 + 底部遮罩调留白」已被四边手柄取代
- **宽度调节为 v3.0.0 新增**（v2.x 只能调高度）
- 底部留白（键盘与屏幕底部的间距）不再从调节界面编辑；此前保存的留白值继续生效
