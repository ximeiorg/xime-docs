# 智能纠错（实验性）

::: info 适用平台
**仅 Android**。这是触屏键盘或 Android 端专属功能，Windows / Linux 桌面版没有对应入口。
:::


智能纠错（v3.2.1+）在你按错相邻键时，于候选栏给出纠正候选，帮助挽回误按。

## 工作方式

- 对整条编码做**邻键误触解码**：任意一位按偏都可能被纠正
- 纠正用词始终来自**当前方案自己的词典**，不会串到其他方案
- 纠正候选标注「纠错」，并排在原有候选**之后**（不抢占正常候选），点选才上屏
- **不会自动替换**你输入的内容；忽略它即可，行为与未开启时完全一致

## 启用

1. 打开「设置」→「智能」→「智能纠错（实验性）」
2. 打开「启用智能纠错」开关（立即生效，无需重启输入法）

## 支持的方案

内置的 `correction.schemas` 为 `[wubi86, wubi86_pinyin, pinyin_simp]`（五笔86、五笔拼音、全拼）。

其他「按键字母 = 编码」的方案可在 `rime/xime.custom.yaml` 同路径**追加**（与内置列表取并集）：

```yaml
correction:
  schemas: [wubi98, wanxiang]
```

> 双拼（字母经拼写运算变换）、九键（数字键）会在「按键 - 编码」对齐检查处自动跳过，不会误纠。

## 注意事项

- 此功能为**实验性质**：仅对默认布局、开发者自身使用习惯做了训练，不承诺对所有用户可用
- **不支持任何自定义按键布局的键位纠错**（改了键位后纠错结果会不准确）
- 纠错结果只在候选栏出现，不会污染你已有的候选
