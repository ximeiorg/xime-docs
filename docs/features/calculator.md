# 计算器

::: info 适用平台
**Android · Windows**。两端都有计算器，进入方式不同；Linux 版暂未提供。
:::


Xime 的数字键盘内置计算器功能，支持数学表达式计算，计算结果可直接输入到文本框中。

## 功能特性

- **四则运算** - 支持加（+）、减（-）、乘（*）、除（/）运算
- **实时计算** - 输入表达式后自动计算并显示结果
- **结果上屏** - 点击计算结果直接插入到输入框
- **表达式中途编辑** - 支持在计算过程中修改表达式

## 使用方法

### 进入计算器模式

计算器模式集成在数字键盘中。切换到数字键盘后，键盘上方会显示计算器输入区域。

### 按键说明

| 按键 | 功能 |
|------|------|
| `+` | 加法 |
| `-` | 减法 |
| `*` | 乘法 |
| `/` | 除法 |
| `=` 或候选栏结果 | 将计算结果提交到输入框 |
| 删除键 | 删除最后一个输入的字符或运算符 |
| 数字键 0-9 | 输入数字 |

### 操作步骤

1. 切换到数字键盘
2. 使用数字键和运算符键输入表达式（如 `12+34`）
3. 候选栏会实时显示计算结果
4. 点击计算结果或按确认键将结果插入到输入框
5. 可以继续输入新的表达式进行计算

### 示例

```
输入：12 + 34
结果：46

输入：25 * 4
结果：100

输入：100 / 3
结果：33.3333
```

## Windows 桌面版（曦码·曜）

> 桌面版使用实体键盘，计算器以 `=` 前缀进入。

### 进入与退出

- 在**中文输入状态、没有正在组词**时按 `=`，候选栏进入计算模式。
- `Esc`、任意字母、`Tab`，或退格删空前缀，都会退出计算模式并把按键交回正常输入。

### 输入内容

- 数字、小数、四则运算 `+ - * /`，以及 `%`、`^`、括号。
- 常量与函数：`pi`、`e`、`sqrt`、`abs`、`ln`、`log`、`exp`、三角函数、`min` / `max` 等。

### 候选与上屏

候选区从算式的第一个字符起就实时显示：

- **可计算**：给出「结果」与「原式」两条，结果默认高亮；
- **未成形**（结尾是运算符、括号未配平）：只显示原式；
- **有错误**（除零、语法错）：显示错误提示，不可上屏。

上屏方式：

- 空格、回车，或再按一次 `=`，上屏当前高亮项；
- 鼠标直接点击某一条候选；
- 方向键按当前候选布局切换：横向布局用 `←` / `→`，纵向布局用 `↑` / `↓`；**另一根方向键仍然退出计算模式并移动光标**。

任何输入或退格都会把高亮重置回「结果」。

### 与方案自带计算器的关系

如果当前方案自己占用了 `=`（自带计算器、把 `=` 加入编码字符，或用 `key_binder` 绑定 `=`），内置计算器会自动让位，`=` 照常交给方案处理，不影响方案功能。

### 数字自动识别

默认开启：组词为空时直接打数字，也会先进入计算缓冲；按运算符、空格、字母或窗口失焦时提交。

- 好处是输入 `12+34` 这种算式不需要先按 `=`；
- 代价是裸数字在提交前会短暂出现在组词串里，打字很慢的人可能被拆开。

不习惯可以关闭，在 `%APPDATA%\xime\rime\xime.custom.yaml` 中写入：

```yaml
calculator:
  auto_detect: false
```

保存后重新部署（或重启输入法）生效。
