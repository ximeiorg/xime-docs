# 更新日志

所有版本的更新记录。

## v2.8.0-beta4

**发布日期**: 2026-09-06

### 新增功能

- **云备份（插件化）** - 备份功能重构为插件架构，配套 WebDAV 备份插件，支持通过任意标准 WebDAV 服务备份/恢复数据；备份范围扩展至应用设置、插件配置、插件包（完整备份模式），T9 自造词随 Rime 用户目录一并纳入
- **腾讯云实时语音识别插件** - 接入腾讯云实时语音识别 V2（WebSocket），支持中英粤及 30 种方言、可选说话人分离引擎与临时热词表
- **九键键盘配置** - `xime.yaml` 新增 `keyboard.t9.side_symbols`，九键左侧快捷符号栏支持自定义，符号超过 4 个时可上下滑动
- **非按键交互振动反馈** - 符号/表情面板、菜单栏、候选栏工具栏按钮、候选翻页、长按删词确认等交互，在开启振动反馈时与按键同款振动

### 修复

- 修复九键（T9）长按候选栏删除自造词失效的问题（全键盘不受影响）

### 移除

- **内置 WebDAV 同步** - 由云备份功能（WebDAV 备份插件）替代，设置页入口同步移除

## v2.6.0-beta3

**发布日期**: 2026-08-08

### 新增功能

- **Lua 脚本插件系统** - 以 Lua 脚本替换旧 DEX/APK 插件架构。插件以 `.xipk`（zip）形式分发，内置 Lua 沙箱，插件仅能通过 `host` API 与宿主交互
- **ASR 插件化** - 新增 `funasr-asr`（阿里百炼）与 `volc-asr`（火山引擎）在线语音识别插件，移除内置本地语音识别
- **插件市场** - 新增扩展商店（方案/模型/插件三合一），支持索引下载、版本选择、SHA-256 校验、信任等级判定
- **插件宿主版本兼容性检查** - 插件可声明 `minHostVersion` / `maxHostVersion`，安装与加载时校验
- **插件图标支持** - 插件可提供文本图标或资源图标
- **插件配置表单** - 插件可通过 Lua 导出设置表单（文本框/密码框/开关/下拉/多选），配置即改即存
- **模型版本管理** - 模型索引支持多版本，可查看更新、按版本下载；新增「本地模型」管理页面
- **rime-wubi 子模块** - 内置方案配置迁移至独立仓库 `kingzcheung/rime-wubi` 子模块统一管理
- **统一部署机制** - 部署基于 SHA-256 配置哈希，未变更时跳过全量编译；增加引擎锁（`ReentrantLock`）防止并发部署阻塞
- **T9 C++ 插件** - T9 输入法 16 个模块全量迁移至 librime C++ 插件（librime-t9），Kotlin 层改为薄包装，JNI 桥接重构（按键 JNI 次数 6→3）
- **候选选中文字颜色配置** - `color_schemes` 新增 `candidate_selected_text_color` / `candidate_selected_text_color_dark` 字段
- **IME 服务架构重构** - 重构输入法服务为接口抽象层（按键路由、会话控制、方案控制、文本提交等拆分）
- **本地模型使用警告** - 使用本地模型时提示耗电与发热警告
- **版本兼容性检查容错** - 非语义化版本号（如 nightly）容错处理

### 改进

- 退格键处理优化 - 合并连续退格请求，候选栏渲染平滑无跳帧
- 候选栏渲染性能优化 - 候选数据与键盘布局状态解耦，减少重绘
- 手写模型检查逻辑统一并支持旧版模型迁移
- 移除标点推理功能（`PunctuationInference` 等）
- 个人词库合并逻辑移除，个人词库页面改为只读查看
- manifest.yaml 解析从 snakeyaml 切换为 kaml
- 固定 rime-wubi 子模块至 tag 2.1.1
- ProGuard 混淆规则优化（仅保留 Kotlin Metadata 注解）

### 修复

- 修复 T9 数字「9」键长按字母错误（WXYZ）
- 修复 T9 多音节候选选择时多余音节数字未被消费的问题
- 修复 T9 退格先回退半提交（预编辑恢复为拼音）再删除输入序列
- 修复 T9 packs 补丁与 PDM 治理冲突导致的部署 hash 抖动 ANR
- 修复 T9 部分提交后的候选词显示问题
