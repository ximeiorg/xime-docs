# 使用与设置

本文按「候选窗 → 面板 → 键盘与快捷键 → 语音 → 设置程序」的顺序介绍曦码·逸的日常使用。

## 候选窗

在任意输入框打字时，候选窗出现在光标附近。它是一块自绘的 `NSPanel`，不抢焦点，点击空白处即收起。

- 候选按顺序编号，数字键 `1`–`9` 选词，`0` 选第 10 个
- 空格选第一个候选；回车、退格等按键按 Rime 方案的定义处理
- 候选窗右侧有 **页码/翻页区**，点击或按 `-` / `=`（部分方案是 `[` / `]`）翻页
- 输入中显示当前编码；五笔方案下编码就是字根串
- 点击候选词直接上屏，不需要先切焦点
- `Esc` 取消当前组字并收起候选窗

> 候选窗位置由 InputMethodKit 给出的光标矩形换算，多屏、缩放与非整数倍缩放的场景下如位置异常，请先记下具体应用与窗口状态再反馈。

## 菜单面板

点击候选窗右侧的**菜单按钮**，候选窗原地切换成面板：

| 入口 | 作用 |
|------|------|
| 剪切板 | 查看本机剪贴板历史，点击条目直接上屏 |
| 快捷发送 | 常用短语列表，点击上屏；条目可带触发编码 |
| 表情 | Emoji 网格，多标签分类，点击上屏 |
| 符号 | 常用符号网格，点击上屏 |
| 语音输入 | 开始 / 停止语音听写 |
| 设置 | 打开内嵌的设置程序 `XimeYiSettings.app` |

面板只负责「消费」：剪贴板与快捷发送的增删、置顶、清空都在设置程序里做。列表按页翻，`Esc` 返回菜单或关闭面板。

## 键盘与快捷键

键盘处理对齐官方 rime 前端（Squirrel）：

| 操作 | 效果 |
|------|------|
| `Shift` | 切换中文 / 英文（Rime `ascii_mode`） |
| `Caps Lock` | 清除当前组字并切换大写态 |
| `Command` 组合键 | 直接透传给当前应用（`⌘C`、`⌘V` 不受输入法影响） |
| `1`–`9` / `0` | 选择候选 |
| `-` / `=` | 候选上一页 / 下一页 |
| 空格 | 选第一个候选 |
| `Esc` | 取消组字 / 关闭面板 |

修饰键按 Squirrel 的策略处理：先抬起、后按下，避免 `Shift` 与字母的先后顺序导致漏字或误上屏。实际的翻页与选词键以当前 Rime 方案的 `key_binder` 为准。

## 剪贴板与快捷发送

- **剪贴板**：自动记录复制过的文本，在面板里点击即可插入。记录只保存在本机。
- **快捷发送**：在设置程序的「剪贴板 → 快捷发送」里维护短语与编码；面板按页浏览，点击上屏。
- **编码触发**：输入编码前缀时把快捷条目注入候选栏——这一能力仍在开发中，当前版本请从面板点选。

## 剪贴板同步

设置程序的「剪贴板 → 剪贴板同步」是**开关式多选**，不是下拉选择：

| 开关 | 说明 |
|------|------|
| 局域网直连 | 与配对过的设备点对点传输，不经第三方服务器；副标题显示「已配对 N 台」 |
| 同步插件 | 安装同步插件后经 WebDAV 等通道跨网络同步，开关名称随已选插件变化 |

勾选即启用；两个都勾时按勾选顺序决定优先级，首个优先，直连掉线超过阈值会自动让位给后面的通道。只勾直连就只走直连，不会被悄悄换掉。两个都不勾时显示「同步已关闭」，剪贴板只留在本机。切换会写进日志，形如 `通道 p2p → plugin`。

配对流程、6 位配对码规则与安全模型见[设备互联](/device-link/)。macOS 端不需要额外安装 ximed，直连节点就跑在输入法进程里，详见[桌面端（曦码·逸）](/device-link/ximeyi)。

同步只同步「当前剪贴板」，不会把历史整体上传。

## 语音输入

1. 在设置程序的「语音转文本」里下载一个本地模型
2. 面板点「语音输入」，或在设置里配置的快捷键触发
3. 说话时显示识别进度，停顿后文本上屏
4. 再次触发或关闭面板结束听写

识别在本机运行，录音不上传。

## 设置程序

从面板菜单「设置」进入，或直接打开 `XimeYi.app/Contents/MacOS/XimeYiSettings.app`。

| 页面 | 作用 |
|------|------|
| 输入方案 | 查看已安装方案、部署、导入方案包、打开数据目录 |
| 词典 | 用户词典与快捷短语的新增、编辑、删除、搜索、备份 / 恢复 |
| 外观 | 浅色 / 深色 / 跟随系统、配色方案、字号、候选数量 |
| 快捷键 | 查看当前快捷键绑定 |
| 扩展商店 | 浏览并安装方案、模型、插件 |
| 插件管理 | 启用 / 停用、卸载已安装插件 |
| 语音转文本 | 下载 / 切换语音模型 |
| 设备关联 | 局域网配对（设备互传），步骤见[桌面端（曦码·逸）](/device-link/ximeyi) |
| 剪贴板 | 剪贴板历史、快捷发送、剪贴板同步 |
| 同步与备份 | WebDAV 打包备份与恢复 |
| 关于 | 版本、运行平台、配置目录、许可证 |

设置程序与 Windows / Linux 共用同一份 `xime-setup` 代码，只有产品名与首页链接是 `XimeYi` 侧注入的。

## 插件

插件运行时对齐 Android 3.0 的 QuickJS 方案（旧的 mlua 运行时已退役）。安装插件后：

- 表情包、符号类插件会往面板里追加页签；
- 同步类插件作为剪贴板同步的「插件通道」；
- 插件的启用与卸载在「插件管理」页。

## 数据与配置

```
~/Library/Application Support/XimeYi/
├── rime/                 # 方案、词典、用户配置、build/ 部署产物
└── ximeyi.log            # 运行日志
```

- 修改 `rime/` 下的方案或 `*.custom.yaml` 后，在设置程序里点「部署」，或重启输入法进程。
- 备份可以直接复制 `~/Library/Application Support/XimeYi`，也可以用「同步与备份」传到 WebDAV。
- 排障先看 `~/Library/Application Support/XimeYi/ximeyi.log`；日志是追加写的，反馈时取相关时间段即可。

## 与其它桌面版的差异

曦码·逸与曦码·曜（Windows）、曦码·澈（Linux）共用引擎、方案、设置程序与插件体系，差别集中在平台层：

- **输入法框架不同**：macOS 走 InputMethodKit，候选窗与面板都是自绘窗口；Windows 走 TSF，Linux 走 KWin 虚拟键盘。
- **快捷键体系不同**：macOS 使用 `Command`，`Shift` 切中英；Windows / Linux 用 `Ctrl` 组合。
- **数据目录不同**：`~/Library/Application Support/XimeYi`，与 `~/.config/xime` 互不影响。
- **分发方式不同**：目前只有源码构建，暂无安装包。
